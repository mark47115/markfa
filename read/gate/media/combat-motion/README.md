# 적군·인컴·지휘관 애니메이션

외신 적 28계통의 세 형태, 외신 혼성 인컴 60종, 지휘관 15명을 묶은 스프라이트 팩입니다.

- 본체 시트 `sheets/`는 64×64 투명 셀, 기준점 (32, 57)입니다.
- 이펙트 시트 `fx/`는 128×96 투명 셀입니다. 기준점은 각 클립의 `overlay.pivot`을 읽습니다. 적과 인컴은 좌향, 지휘관은 내 라인에서 우향입니다.
- `manifest.json`의 `frames`는 [x, y, 너비, 높이]이고 `durationMs`는 셀을 표시하는 밀리초입니다. 본체와 이펙트는 각 클립의 시작 시각을 공유하며 각각의 시간표로 재생합니다. 본체가 회복 자세에 돌아온 뒤에도 구역 이펙트가 이어질 수 있습니다.
- 본체와 이펙트의 기준점을 같은 발 위치에 맞춥니다. 고정 목표인 지휘관은 대기·피격·고유 효과·사망을, 증폭핵은 대기·증폭·사망을 사용합니다. 적과 인컴의 대기와 이동은 반복합니다.
- `cue.timeMs`는 발동 또는 접촉 시점이며, `beats`는 능력 발동에서부터 각 후속 연출이 시작할 때까지의 밀리초입니다. `telegraphMs`는 화면에 표시하는 예고 길이입니다. 사망 발동 능력은 사망 시트와 같은 클립에 들어갑니다.
- 기본 공격만 있는 인컴은 해당 공격 클립을 씁니다. 보호막·회복·촉진은 그림과 시간을 담은 시트입니다. 게임에서 받는 대상, 실제 이동, 피해, 상태 제거, 자원 정산은 전투 규칙에서 연결합니다. 미리보기의 피사체 상대 위치는 전장의 고정 좌표를 정하지 않습니다.

공격 생성 그리드와 제작 소스는 프로젝트의 `media/combat-motion/source/`에 있습니다.
