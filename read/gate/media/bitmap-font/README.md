# 게이트 이미지 폰트

**게이트 텍스트**는 인게임 HUD, 카드, 설명용입니다. **게이트 전투**는 데미지, 치명타, 회복, 방어 등 짧은 연출용입니다. 둘 다 각진 도트 획과 같은 숫자 원형을 사용합니다.

| 용도 | 권장 표시 | 특징 |
| --- | --- | --- |
| 글 작성 | 16px 기본, 32px 제목 | 직립 글자, 한 색, 같은 폭의 숫자 |
| 전투 연출 | 숫자 높이 22px 기본, 치명타만 약 1.25배 | 계단형 기울기, 2px 어두운 외곽선, 3단 명암 |

본문은 한글 완성형 11,172자, 호환 자모, 영문, 숫자, 기본 기호를 포함합니다. 전투용은 숫자와 부호, 영문 대문자, 전투 문구용 한글을 포함합니다. 한글 입력은 NFC로 정규화합니다. 전투용 컬러 변형은 같은 글리프 좌표와 전진폭을 사용합니다.

## 가져오기

- `gate-text.fnt`는 흰색 알파 PNG 아틀라스 세트입니다. 씬에서 글자색을 지정합니다. `gate-text.woff2`는 같은 글리프를 HTML 텍스트로 쓰는 파일입니다.
- `gate-damage.fnt` 일반 피해, `gate-critical.fnt` 치명타, `gate-heal.fnt` 회복, `gate-guard.fnt` 방어는 색이 적용된 PNG입니다.
- `.fnt`는 BMFont 텍스트 형식입니다. 같은 폴더에 연결된 PNG를 둡니다. 텍스처 샘플링은 Nearest, 밉맵은 끕니다. 소수 배율보다 정수 배율, 소수 좌표보다 픽셀에 맞춘 좌표를 우선합니다. 회복은 플러스 부호, 방어는 짧은 상태어, 치명타는 크기와 밝기로 함께 구별합니다.
- `body.json`과 `effects.json`은 같은 메트릭을 게임 코드에서 읽는 파일입니다. 글리프 행은 `x, y, width, height, xoffset, yoffset, xadvance, page` 순서입니다. 오프셋은 줄 위쪽과 글자 시작점을 기준으로 하며, `base`는 줄 위쪽부터 기준선까지입니다.

## 원본과 라이선스

본문 한글·영문·기호와 연출용 글자의 바탕은 Lee Minseo의 갈무리 11 볼드입니다. 숫자 10자와 전투 색·외곽선·광택을 이 프로젝트용으로 제작했습니다. 폰트 파일은 SIL Open Font License 1.1로 함께 배포합니다. [갈무리 고정 원본](https://github.com/quiple/galmuri/tree/71e1cacf1437a11220307120e63e30bc275312d4) · [라이선스 전문](OFL.md)

`source/build.py`에 숫자 원본 획과 아틀라스 생성기가 있습니다. 같은 폴더의 BDF와 함께 Pillow, fonttools, Brotli가 설치된 Python에서 실행하면 재생성합니다.
