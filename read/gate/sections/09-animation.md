**승인된 도트를 기준으로 핵심 자세를 만들고, 자세 사이의 동작과 재생 시간을 조립합니다.** 이 정책은 캐릭터 본체와 몸에 달린 장비의 움직임에 적용합니다. 공격 준비, 타격·발사 순간, 수습 자세는 본체만 재생해도 읽혀야 합니다.

## 공통 규격

- **원본 도트 기준.** 얼굴, 체형, 무기를 쥔 손, 장비와 실루엣은 승인된 유닛 도트에 맞춥니다. 약간 위에서 보는 ¾ 시점과 2D 도트의 계단형 외곽선을 유지합니다. 사람형은 2~2.5등신을 기준으로 하고, 본체 한 형태에 쓰는 불투명 RGB는 최대 10색입니다. 그림자 진영은 검정과 흑연색을 바탕으로 눈과 장비에 보라색을 제한적으로 씁니다. [기준 도트](../unit-sprites.html) · [아트 방향](../index.html#direction)
- **시트와 방향.** 타워·적·인컴은 64×64 투명 RGBA 셀과 발 기준점 (32, 57)을 씁니다. 지휘관은 원래 도트 크기로 무기 궤적을 담기 위해 112×96 셀과 발 기준점 (48, 72)을 씁니다. 타워와 내 지휘관은 우향, 외신 적과 인컴은 좌향입니다. [아군 가져오기 규격](../media/tower-motion/v8/README.md) · [전투 모션 가져오기 규격](../media/combat-motion/v9/README.md)

## 제작 방식과 타이밍

1. **기준 도트에서 핵심 자세를 제작합니다.** 이미지 생성이 필요한 경우 모델 ID를 지정하지 않고 기본 OpenAI ImageGen을 사용합니다. 투명한 그리드에 한 셀당 한 자세를 그리고, 자세별 순서와 생성 지시를 기록합니다. 핵심 자세는 준비 → 체중 이동 → 접촉 또는 방출 → 뒤따르는 움직임 → 수습 순입니다. [아군 원화 제작 지시](../media/tower-motion/source/key-poses/prompts.md) · [전투 원화 제작 지시](../media/combat-motion/source/prompts.md)
2. **셀 정렬과 중간 자세는 제작 스크립트로 조립합니다.** 원화를 자르고 팔레트와 발 기준점을 맞춥니다. 보행은 사람형·짐승·곤충·비행형의 다리와 몸통이 다르게 움직이도록 만들고, 큰 무기는 몸의 체중 이동에 맞춰 따라오게 합니다. 검의 올려베기·내려베기·찌르기, 짐승의 물기·앞발 공격은 서로 다른 전신 동작을 씁니다. 활은 화살 걸기 → 당겨 고정 → 손을 풀어 방출, 지팡이는 정해진 방향으로 내밀거나 들어 올리는 자세를 씁니다. 손에 든 활, 활시위와 걸린 화살은 본체에 그립니다. [근접 동작 제작 규칙](../media/melee-motion/source/README.md) · [활·지팡이 제작 규칙](../media/ranged-motion/source/README.md)
3. **프레임 유지 시간은 클립별로 저장합니다.** 인컴 초안은 대기 8fps, 이동·공격·스킬·사망 12fps를 원화 제작 기준으로 삼습니다. 실제 재생은 `durationMs`를 따릅니다. 대기와 이동은 반복하고, 공격·스킬·피격·사망은 한 번 재생합니다. 개정된 근접 기본 공격은 14프레임으로 준비·접촉·수습을 읽히게 합니다. 모션을 고칠 때도 확정된 발동 시각과 전체 재생 길이를 기준으로 삼습니다. [인컴 제작표](../income-motion-plan.html#frame-title) · [근접 모션 개정](../media/combat-motion/v2/README.md)
4. **지휘관은 승인된 대기 도트의 얼굴·머리·갑주·팔다리를 전투 자세에도 사용합니다.** 각 부위를 원래 픽셀 크기로 연결합니다. 디딤발 위에서 골반과 어깨가 움직이고, 팔꿈치와 손목을 따라 무기가 돌거나 손이 뻗습니다. 벨리온의 양쪽 날개와 이그리트의 투구 깃은 원본 도트에서 분리해 회전시킵니다. 안타레스는 목과 턱을 열어 숨결을 내보냅니다. [지휘관 제작 규격](../media/combat-motion/v9/README.md)

## 내보내기와 확인

- **소스와 납품 파일.** 생성 원화, 그리드 순서, 셀 자르기·정렬 스크립트를 보관합니다. 납품본은 본체·이펙트·범위 PNG 시트와 `manifest.json`입니다. `frames`에 셀 사각형 `[x, y, w, h]`, `durationMs`에 프레임별 밀리초, `loop`에 반복 여부를 기록합니다. `cue.timeMs`는 해당 미리보기의 접촉·방출·고유 능력 발동 시점이며, 장비에 연결하는 동작은 필요한 경우 `cue.socket`과 `cue.localAnchor`도 기록합니다. [아군 프레임 데이터](../media/tower-motion/v8/manifest.json) · [외신·인컴·지휘관 프레임 데이터](../media/combat-motion/v9/manifest.json) · [재생·내보내기 규격](../media/standard-motion/source/README.md)
- **재생 검수.** 미리보기에서 이펙트 표시를 끈 뒤 1배속과 0.5배속으로 확인합니다. 32px와 64px에서 실루엣·방향·장비, 접지와 프레임 경계, 반복 이음새, 준비와 접촉 자세가 읽혀야 합니다. 다수 교전에서는 본체 움직임이 서로 구분되는지 확인합니다. [아군 타워 재생](../ally-tower-animation.html) · [적군·인컴·지휘관 재생](../combat-animation.html) · [먹결 정찰개미 재생](../scout-ant-animation.html)
- **전투 연동.** 실제 이동 좌표, 사거리·대상·피해와 상태 변화는 전투 규칙에서 결정합니다. 지휘관은 발 기준점을 한 자리에 두고 기본 공격·피격·사망 클립을 재생합니다. 사망 확정 시 진행하던 공격을 닫고 사망 클립을 한 번 재생합니다. 웨이브가 끝나면 기물은 저장한 배치 칸과 형태로 복귀합니다. [전투 진행 규칙](../index.html#core-loop)
