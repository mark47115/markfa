# 평타·액티브·패시브 이펙트

## v12 · pixelfx로 다시 그린 병종 이펙트

병종 모션과 스킬 이펙트 탭의 136종, 기술 168개, 기본 공격 136종을 pixelfx 이펙트로 다시 그렸다. 기술 데이터의 단서 모양 48종을 이펙트 묶음 10개(투사체, 근접, 적중, 연결선, 바닥 예고, 발밑 파동, 보호막, 회복, 상태 표식, 이상 상태)로 나누고, 병종의 색·재료·진영과 단서의 출발점·도착점·길이로 그린다. 역류의 종지기는 전용 이펙트 6종(열 예고, 파도, 둔화, 추 끌어올리기, 물막 판, 판 깨짐)을 쓴다. [병종별 GIF](../battle-effects.card.json) · [실시간 재생](../media/unit-sprites/battle-actions/index.html)

## v11 · 전투에서 읽히는 도트 이펙트

아군·공허 유닛 308종의 평타, 액티브 14종, 패시브와 상태 효과를 다시 그렸다. 평타는 무기별 궤적, 투사체의 밝은 선두와 잔상, 적중 지점에서 퍼지는 섬광과 파편으로 구분한다. 활·석궁·투창은 화살의 길이와 끝 모양이 다르고, 포탄·씨앗·마력탄은 핵과 궤적으로 구분한다. 평타와 투사체는 기존 타격점·발사구·적중 틱에 연결한다.

범위 스킬은 어두운 외곽의 붉은 점선으로 예고한다. 확정 시 같은 반경에 스킬 색의 충격파가 번지며, 불씨·발톱·전류·바위 파편을 구별한다. 중단 시 예고를 걷는다. 보호막은 몸 양옆에 판이 펴지고, 회복 십자와 부활 핵은 위로 오른다. 둔화와 추격 표식은 발밑에서 구별한다.

100대100에서는 화면 구역마다 겹친 평타를 하나로 줄이고 한 프레임에 최대 16곳의 몸체 적중 효과를 그린다. 스킬은 평타와 상태 효과 위에, 체력바는 이펙트 위에 그린다. 브라우저의 **주변 유닛 100기** 옵션에서는 밝은 풀밭과 어두운 균열을 바꿔 개별 효과를 볼 수 있다. [이펙트 재생](../combat-vfx.html?mode=active&unit=allies-050&dense=1&overlap=1&terrain=rift) · [308종 이펙트 배정](../media/unit-sprites/unit-motion-v10/battle-vfx-profiles.json) · [Unity 검수](../docs/unity-battle.md#v11--전투-이펙트)

런에 아직 연결되지 않은 공허군의 일부 권능은 브라우저에서 자세와 이펙트를 재생한다. 삼키는 자의 분열과 갈라진 예언자의 지정 열 타격이 여기에 해당한다. [공허군 권능](../docs/enemy-character-design.md)

평타는 밝은 순간 뒤 바깥으로 흩어지는 파편만 남긴다. 액티브는 준비, 확정, 잔류를 구분하고, 패시브는 조건이 충족된 유닛 근처에 각각의 실루엣을 표시한다. [재생과 비교](../combat-vfx.html)

## 브라우저의 시전자와 도착 지점 표시

| 단계 | 플레이어가 보는 표시 |
| --- | --- |
| 준비 | 시전자의 체력바 위에 몸을 가리키는 도트 쐐기가 붙는다. 무기 작용점에 작은 불빛을 두고, 위치 지정형 공격은 지면에 고정한 붉은 테두리와 중심점을 보여 준다. |
| 발사·전달 | 무기에서 나간 선두 도트 뒤에 짧고 성긴 잔상이 따른다. 화살과 돌은 기존 비행 경로를 따르고, 약병은 포물선, 동력 분배는 바닥 전류를 따른다. 표식 꿰기는 확정된 두 번째 표적이 있을 때 경로가 한 번 더 이어진다. |
| 도착 | 유닛 발밑 양옆에 모서리를 표시한다. 비행 중에는 조준한 위치를 옅게 표시하고, 적중이나 지원 적용 시 모서리 끝을 밝힌다. 시전자 중심 범위 공격은 반경이 먼저 읽히고 적중이 확정된 유닛에 모서리가 붙는다. |
| 종료 | 대상 확정 뒤 0.15–0.24초 안에 공통 표시가 사라진다. 보호막·둔화 같은 지속 효과는 고유 모양으로 보여 준다. 준비 중단 시 해당 시전의 쐐기, 예고, 진행 표시를 함께 걷는다. |

쐐기와 모서리는 황동·이끼색·먹보라 팔레트에 어두운 외곽을 두른다. 시전자와 표적은 위치와 실루엣으로 구별하며, 혼전에서는 잔상의 수를 줄인다. ‘동시 시전’으로 아군 화살과 공허 포격이 교차하는 장면을 재생할 수 있다. [동시 시전 재생](../combat-vfx.html?mode=basic&unit=sprout-archer&terrain=rift&dense=1&overlap=1)

## 도트와 색

- 경계가 계단진 도트에 어두운 테, 계열 중간색, 밝은 심을 넣는다. 브라우저는 480×270 논리 화면에 선형 보간 없이 그린다. 가장 밝은 도트는 타격 초반과 스킬 작용점에 집중한다.
- 아군은 황동·뼈색, 이끼·새잎색, 전기 청회색, 불씨 주홍색을 사용한다. 공허는 계열의 먹자두·청회색과 밝은 핵으로 읽힌다. 두 진영의 위험 범위 예고는 붉은 바닥선이다.
- 범위 표시의 중앙을 비워 둔다. 혼전에서는 파편과 잔상의 개수를 줄이고 보호막과 회복은 인물 양옆에 놓는다.

## 기본 공격

아군과 공허 308종을 19가지 기본 공격 형태에 연결했다. 도트 궤적은 무기 끝, 투사체는 발사구, 명중 파편은 피격 대상에서 시작한다. 공허 원거리 발사는 핵·촉수·거울·포구에서 방향을 읽는다. [도트 화살 재생](../combat-vfx.html?mode=basic&unit=sprout-archer) · [무기 원본 모션](../ally-animation.html)

| 무기 | 평타에서 읽어야 할 형태 |
| --- | --- |
| 검·도끼·창 | 검과 도끼의 휘는 짧은 궤적, 창이 나가는 곧은 도트 |
| 방패·둔기·주먹 | 방패 앞 모서리의 충돌선, 둔기의 낮은 파편, 주먹의 짧은 두 줄 잔상 |
| 발톱·턱 | 서로 평행한 긁힘, 마주 닫히는 두 쐐기 |
| 활·석궁·총포 | 길이가 다른 화살 자국, 짧은 직선 탄도, 총구 섬광 |
| 투창·돌 | 투창의 긴 끝과 짧은 낙하, 돌의 둥근 도트와 높은 포물선 |
| 지팡이·전하·악기 | 가장 밝은 핵이 있는 투사체, 각진 전류, 간격이 벌어지는 음파 |

## 유닛 액티브 14종

| 유닛 · 기술 | 실행되는 모양 |
| --- | --- |
| 수관 재배사 · 푸른 그늘 | 잎이 선택된 아군 양옆까지 이동하고, 보호막이 남은 동안 잎 모서리가 몸 바깥을 받친다. |
| 가죽 정비공 · 예비 장전 | 황동 장전핀이 아군 무기 가까이에 걸리고 다음 유효 기본 공격이 소비할 때 짧게 터진다. |
| 가시언덕 몰이꾼 · 추격 신호 | 같은 기물의 대상 발 앞에 진행 방향으로 쐐기 두 개가 붙는다. |
| 성문 교대기사 · 방패 교대 | 겹친 방패 모서리가 호위 대상 앞에서 닫힌다. |
| 분기 조립기 · 동력 분배 | 바닥을 두 번 꺾는 전류가 선택된 영구 작업 로봇까지 이어지고 전하 마디가 붙는다. |
| 약통 상인 · 응급 약병 | 낮게 던진 약병이 확정 대상 앞에서 열리고 회복 도트가 옆으로 오른다. |
| 협곡 북대장 · 후속 북소리 | 북면에서 청록 음파가 나가며 강화 받은 유닛 옆에 호박색 박자 표시가 남는다. |
| 얼룩 스라소니 · 갈퀴 휩쓸기 | 발밑의 붉은 원형 예고가 닫히고, 세 갈래 발톱 궤적과 적중한 대상의 파편이 이어진다. |
| 잉걸 사수 · 불씨 산탄 | 고정된 바닥을 예고한 후 산탄이 여러 갈래로 퍼지고, 적중 지역에 낮은 불씨가 흩어진다. |
| 늑대 투창수 · 표식 꿰기 | 표식의 두 마디가 닫힌다. 첫 표적부터 판정된 두 번째 표적까지 짧은 관통 자국이 이어진다. |
| 집행관 · 서약의 반격 | 발밑의 원형 예고 뒤 도끼의 끊어진 원호가 번지고 뼈색과 자주색 조각이 떨어진다. |
| 축전 관제 본체 · 축전 방전 | 반경에 청회색 전류가 가고, 실제 보호막이 줄어든 대상에 두 갈래 파편을 낸 뒤 피해를 표시한다. |
| 금고 방패병 · 방패 견제 | 방패가 전방에서 맞닿은 뒤, 느려진 적 옆에 떨어진 두 눈금이 남는다. |
| 진홍뿔 타우렌 · 분노 짓밟기 | 압력이 퍼진 방향으로 바닥이 계단 모양으로 갈라지고 작은 돌조각이 가라앉는다. |

시전 시간 250–500ms와 원형 피해 범위는 스킬 표를 따른다. 지원 스킬은 확정된 수신자에게만 효과 표시를 붙인다. 표식 꿰기의 두 번째 타격과 축전 방전의 보호막 파편은 해당 판정이 있을 때 발생한다. [유닛 액티브 규칙](../docs/unit-active-skills.md)

## 유닛 패시브

브라우저의 유닛별 고유 효과 170건은 16가지 판정 모양을 공유한다. 첫 유효 적중 둔화는 발목으로 내려오는 꺾쇠, 추가 피해는 기존 착탄 뒤의 두 쐐기, 경감은 충돌 쪽의 짧은 방어면이다. 보호막은 몸 양옆에 표시하고 파괴는 두 조각으로 끊는다. 회복은 위로 오르는 십자, 이동 가속은 발 뒤의 세 눈금으로 읽힌다. [평타와 둔화 재생](../combat-vfx.html?mode=passive&unit=seedling-keeper)

공허 도발은 바닥의 갈고리, 공격력 성장은 무기 옆 마디, 부활은 몸이 사라진 자리의 부유 핵, 분열은 두 분열체 위치로 갈라지는 핵을 사용한다. 첫 사거리·장전, 피격 반격, 공격력 감소와 측면 접근도 각각 고유한 모양을 쓴다. [패시브 대표 도트](../media/combat-vfx/passives.png) · [공허 유닛별 판정](../docs/enemy-character-design.md) · [유닛별 연결과 원본 코드](../combat-vfx-catalog.mjs)

## 이벤트 연결

| 이벤트 | 표시 위치와 종료 |
| --- | --- |
| 기본 공격 발사·명중 | 준비 중에는 투사체를 띄우지 않는다. 발사 위치는 시전자 로컬 작용점, 비행과 명중 위치는 전투의 투사체와 실제 적중을 따른다. 빗나감과 취소는 명중 파편을 만들지 않는다. |
| 액티브 준비 | 위치 지정은 바닥 좌표를 고정하고, 시전자 중심형은 시전자와 함께 움직인다. 중단 시 예고와 준비 파편을 같이 닫는다. |
| 액티브 완료·패시브 발동 | 실제 확정된 대상과 피해·회복·보호막 감소 사건에 맞춰 한 번 재생한다. 대상이 없는 효과는 적용 표시 없이 끝난다. |
| 상태 잔류 | 대상에게 동일 상태 표시를 하나 유지한다. 지속시간 갱신, 다음 명중 소모, 보호막 파괴, 퇴장 이벤트에서 갱신하거나 닫는다. |
| 공허 부활·분열 | 실제 원본 퇴장 위치와 부활·생성 위치를 따른다. 분열은 배치된 소환체마다 핵의 끝점을 하나 기록한다. |

브라우저 재생은 모션 원본과 고정된 표적 배치를 사용한다. 자동 검사는 기본 공격 변형 370건, 액티브 14건, 패시브 170건의 렌더링과 액티브 준비 중단 시 표시 제거를 확인한다. Unity에서는 시뮬레이션이 생성하는 이벤트에 이펙트를 연결한다. [브라우저 검사 코드](../qa/combat-vfx-readability.mjs) · [도트 그리기 코드](../combat-vfx-drawing.mjs) · [공격 모션 규격](09-animation.md)
