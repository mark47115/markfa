# Tavern Heros · 유닛 전투 AI와 오토배틀 알고리즘

전투는 **20Hz 고정 틱**으로 처리한다. 출전 위치가 첫 타깃과 합류 시간을 바꾼다. 같은 시드·콘텐츠 버전·편성은 같은 결과와 로그를 낸다. 시험값은 구현 후 검증한다. [전투 설계](combat-design.md) · [액티브 14종](unit-active-skills.md) · [전장과 장애물](battle-map-design.md)

## 오토배틀 틱과 사건 순서

### 출전 · 0틱

편성을 확정하고 기물·대장 효과를 적용한다. 아군 상태와 지정 대상을 저장한 뒤 시작 권능과 첫 행동을 처리한다. 저격·강탈·파막은 이 출전 보너스가 반영된 상태를 읽으며, 저격은 피격으로 세지 않는다.

### 매 틱의 판정 순서

1. **진행**\
   이동·공격 준비·회복·시전을 진행한다. 상태는 시작 틱부터 만료 직전까지 유효하다. 만료 상태를 빼고 예정된 부활·분열체를 배치한다. 심해 파동은 3초에 이동을 마친 열을 예고한다.
2. **확정**\
   같은 위치·생존 상태에서 타격·착탄·시전 완료·시간제 권능을 확인한다. 보호막·회복·버프 반영 뒤 피해량을 정한다. 중단 시전은 제외한다. 같은 틱에 확정된 공격은 서로를 쓰러뜨려도 모두 적용한다.
3. **피해**\
   예정 틱 → 출처 안정 ID → 출처별 순번으로 처리한다. 권능의 고정 ID는 유닛보다 앞선다.

   첫 피해 경감 → 호위 → 보호막 → 남은 피해 경감(에다 등) → 체력 순이다. 보호막은 만료 틱·부여 순으로 소모한다.

   범위 공격 1회는 사건 ID를 공유한다. 같은 묶음에서 체력 0인 대상의 추가 타격은 과잉 피해로만 기록한다. 체력 피해와 처치 보상은 추가하지 않는다.
4. **후속 효과**\
   피해 묶음 뒤 생존 조건 효과(나린 등)를 처리하고 부활을 예약한다. 최종 퇴장에는 분열·처치 기여·응징·표식·잔향을 적용한다. 새 피해는 같은 틱의 다음 묶음으로 보낸다. 원인 ID를 계승해 효과별 재발동 상한을 적용한다.
5. **종료 또는 다음 행동**\
   생존·부활 대기·분열 배치를 확인한다. 적만 전멸하면 승리, 동시 전멸하면 아군 패배다. 600틱 끝에 양쪽 전력이 남으면 무승부다. 15라운드는 보스·호위·분열체를 모두 쓰러뜨려야 한다. 전투가 이어질 때만 다음 조준·이동·시전을 정한다. [침식과 보스 규칙](run-rules.md)

## 입력과 전투 상태

| 항목 | 결정 기준 |
| --- | --- |
| 출전 입력 | 시드, 규칙 버전, 전장·적 편성 ID, 대장, 아군 슬롯·유닛 순서·변신·강화, 권능과 출전 지정 대상. |
| 전장 | 20×16 월드 단위, 탐색 격자 0.25 단위. 화면 왼쪽이 아군(+z), 오른쪽이 적(−z)이다. 화면 위·가운데·아래가 전술 좌·중·우 열이며 `x < −3.75`, `−3.75 ≤ x < +3.75`, `+3.75 ≤ x`로 구분한다. |
| 유닛 ID와 소속 | 전투 ID는 진영·슬롯·편성 순번으로 정한다. 부활하면 생명 번호만 올린다. 영구 증원은 소속 기물·생산 출처·유형을 편성에 저장한다. 분열체와 소환물에는 생성 원인과 순번으로 별도 ID를 준다. |
| 현재 상태 | 위치·반경, 체력, 보호막·만료, 출발 열·전후열, 타깃·접근 자리 예약, 공격 준비·회복, 시전·재사용 대기, 부활 예약, 패시브 횟수. |
| 시간·수치 | 1틱 0.05초. 0틱 출전, 600틱(30초) 제한. 좌표는 1/1000 단위 정수다. 이동의 소수 잔여는 다음 틱에 넘긴다. 반올림은 최근접 정수, 정확히 절반이면 0에서 먼 쪽이다. 사거리와 충돌은 거리 제곱으로 판정한다. |

출전은 슬롯·편성 순서대로 배치한다. 겹치면 아군 또는 적의 출전 구역 안에서 가까운 빈 격자를 찾는다. 동률은 같은 전술 열, 격자 번호 순이다. 빈자리가 없으면 출정 전에 문제 배치를 표시한다. 위치를 옮겨도 출발 슬롯·전후열은 유지한다.

## 유닛 AI

매 틱 위에서부터 가능한 행동을 고른다. 길이 막히거나 목표·타격 위치가 바뀌면 경로를 다시 찾는다.

1. **퇴장·부활 대기·행동불능.** 이동과 새 행동을 멈추고 확정 전 공격·시전을 취소한다. 발사한 공격은 발사 시 판정과 대상 생명 번호를 유지한다.
2. **시전·공격 준비.** 진행 중인 행동을 이어 간다. 타격·발사 전 대상이 죽거나 사거리를 벗어나면 공격을 취소한다.
3. **액티브.** 시점·대상·횟수 조건이 모두 맞으면 다음 기본 공격보다 먼저 시전한다. 시전 중에는 기본 공격 회복이 멈춘다. [시전과 취소 규칙](unit-active-skills.md)
4. **기본 공격.** 새로 조준할 때 사거리 안 도발을 우선한다. 준비 중인 공격은 대상을 유지한다. 회복이 끝나면 공격을 준비하고, 회복 중이면 사거리 안에서 기다린다.
5. **이동.** 사거리 밖이면 타격 자리로 접근한다. 대상이나 길이 없으면 제자리에서 다음 대상을 찾는다.

### 조준 우선순위

- **근접·탱커.** 사거리 안 도발 → 도달 가능한 전열 → 도달 가능한 다른 적 순으로, 같은 그룹에선 가까운 적을 고른다. 전열 자리가 막혀 0.6초 동안 우회도 못 하면 다른 적을 본다.
- **원거리.** 사거리 안 도발 → 사거리 안 최근접 적 → 접근 가능한 최근접 적 순이다. 기본 사거리는 반경을 뺀 거리 4.6이며, 사거리에 들면 멈춘다. 지원 유닛은 사거리 안 지원기를 먼저 검사한 뒤 무기 규칙을 따른다. 별도 추격은 스킬이 지정한다.
- **특수 조준.** 유닛별 발동 시점과 대상을 따른다. 모래 잠복자는 같은 쪽 후열 → 같은 쪽 전열 → 최근접 생존 적 순이다. 추격 기여는 다음 선술집에 남긴다. 도발은 기본 공격에 적용하며 사냥 표식·액티브·권능은 각자의 지정 규칙을 쓴다.
- **대상 변경.** 유효한 대상과 자리는 유지한다. 새 사거리 내 도발, 퇴장·부활 대기, 강제 재조준, 길 막힘 때 바꾼다. 원거리 유닛이 접근 중이면 사거리에 들어온 다른 적에게 전환한다. 거리 동률은 **출발 전열 → 전술 왼쪽 → 슬롯 → 편성 순번 → 새 유닛의 생성 순번**으로 푼다.

### 이동, 정체, 타격 위치

1. **타격 위치.** 근접은 적 둘레 8방향의 `양쪽 반경 합 + 사거리의 90%` 지점과 가까운 셀을 찾는다. 몸이 겹치지 않고 `중심 거리 − 양쪽 반경 ≤ 사거리`여야 한다. 기본 사거리는 0.9다. 8방향이 막히면 사거리 안 다른 셀을 본다. 원거리는 사격 가능한 현재 위치 또는 경로상 사거리 진입 첫 셀을 쓴다. 지형은 시야를 막지 않는다.
2. **경로 예약.** 장애물과 원형 몸체를 검사한다. 일반·대형 반경 시험값은 0.45·0.75다. 직선이 막히면 8방향 A*를 쓴다. 직선 비용 250, 대각선 354이며 대각선 양옆이 열려야 한다. 최단 경로를 택하고 동률은 출발 열·격자 번호 순이다. 도착 위치는 겹칠 수 없다. 대상 변경·퇴장·재탐색 때 반납하고, 적이 예약 위치의 사거리를 벗어나면 다시 잡는다.
3. **동시 이동.** 같은 직전 위치에서 이동을 제안한다. 대기 시간이 긴 유닛부터 검사한다. 동률은 틱마다 우선 진영을 바꾸고 같은 진영에서는 안정 ID를 쓴다. 확정 궤적과 남은 점유를 검사해 통과·자리 맞교환을 막는다. 옆으로 피할 수 없으면 기다린다.
4. **정체.** 6틱(0.3초) 동안 0.05 단위도 전진하지 못하면 같은 적의 다른 자리를 찾는다. 12틱(0.6초)에도 자리가 없으면 다른 적을 고른다. 공격·시전·행동불능 시간은 정체에서 뺀다. 이동 시험값은 초당 2.8, 틱당 0.14 단위다.

### 기본 공격과 액티브 시간

- 근접 기본 주기는 **22틱(준비 7, 회복 15)**, 원거리는 **28틱(준비 9, 회복 19)**으로 시작한다. 공격속도는 남은 준비·회복의 진행 속도를 바꾼다. 신규 버프가 걸려도 이미 진행한 양은 남는다. 시전 시작 시점에서 표의 시전 틱만큼 경과한 시점에 완료한다. 예를 들어 80틱에 시작한 0.35초 시전은 87틱에 완료한다.
- 타격이나 발사를 확정하기 전에 사거리나 대상이 무효가 되면 해당 공격은 피해 없이 취소하고, 다음 행동에서 새로 준비한다. 원거리 발사 뒤에는 사거리를 다시 비교하지 않는다. 기본 투사체 속도는 초당 10 단위를 시험하며, 비행 시간은 발사 시 중심 거리로 계산해 올림한다. 도착 시 대상 ID와 생명 번호가 맞고 살아 있어야 한다. 발사 전에 취소한 공격은 첫 적중 보너스를 소모하지 않는다.
- 액티브는 대상이나 바닥 위치를 시전 시작에 고정한다. 대상 지정형은 완료 시 같은 대상의 생존과 필요한 범위를 확인하고, 위치 지정형은 그때 고정 범위 안에 있는 유닛에게 적용한다. 시전 중 중단과 전투당 1회 소모는 스킬별 공통 규칙을 따른다. [아군 액티브](unit-active-skills.md)

## 예외와 재현 조건

- **부활.** 첫 사망에 부활권을 소모하고 8틱(0.4초) 뒤에 원래 유닛 ID, 새 생명 번호로 돌아온다. 부활 대기 중엔 타깃·충돌 대상에서 빠지고, 전멸 판정에서는 살아날 전력으로 센다. 사망 위치가 점유됐으면 같은 열의 가까운 유효 격자를 먼저 찾는다. 자리가 전혀 없으면 다음 틱에 재시도한다. 복귀한 유닛은 그 틱이 끝난 뒤 새 행동을 정하며 라운드당 액티브·패시브의 소모 기록은 유지한다.
- **최종 퇴장과 분열.** 삼키는 자가 최종 퇴장하면 사망 위치를 비우고 분열체 두 기를 같은 틱에 넣는다. 첫 후보는 실제 사망 위치다. 다음 후보는 사망 위치와 깊이 `z`가 가장 가까운 적 슬롯의 줄에서 `x` 거리가 짧은 순이며 동률이면 전술 왼쪽을 우선한다. 반대 줄과 주변 격자를 차례로 검사하며 실제 충돌이 있는 후보는 건너뛴다. 공간이 없으면 다음 틱에 재시도하며, 생성 대기 중인 분열체도 전멸 판정에서 전력으로 센다. 호위는 자기 위치를 유지한다.
- **처치·피해 기여.** 추격은 적 원본이 최종 퇴장할 때 최근 40틱 이내의 체력 피해를 확인한다. 한 기물이 여러 유닛으로 같은 원본에 피해를 줘도 기여를 한 번 센다. 사냥 표식은 지정한 원본 슬롯의 최종 퇴장을 세며 분열체는 새 원본이 아니다. 응징은 원본 편성의 마지막 생명까지 확인한다. 웨이브 직접 피해는 유닛의 추격·격노를 발동하지 않는다.
- **권능 예고.** 심해 파동은 60틱에 점유한 전술 열을 저장하고 80틱에 저장된 각 열의 가장 앞 아군을 다시 고른다. 아군의 앞쪽은 `z`가 작은 방향이다. 빈 열은 빗나가며, 일반 AI는 예고를 보고 별도 회피 명령을 만들지 않는다. 평소 이동과 공격 위치 선택으로 열이 바뀔 수 있다.
- **기록과 재생.** 전투는 고정 정수 난수로 처리한다. 동률은 정렬로 해결하고 무작위가 명시된 효과만 난수를 쓴다. 공격, 착탄, 스킬 장판은 각각 확정된 로그의 준비·발사·적중·시전 완료 틱에 맞춰 재생한다. 화면 프레임과 애니메이션 재생은 판정 입력에서 제외한다. 로그에 틱, 이벤트·원인 ID, 시전자, 대상의 ID·생명 번호, 효과량과 종료 사유를 적는다. 같은 입력을 1배·2배로 보거나 화면 없이 반복해도 전투 결과와 로그 해시가 같아야 한다. [전투 이펙트 미리보기](../combat-vfx.html)

경로 탐색은 장애물과 충돌 반경으로 만든 격자를 전장별로 재사용한다. 한 틱에서 탐색할 요청 수를 고정해 같은 시드의 느린 기기에서도 판정 결과가 달라지지 않게 한다. 시작 시험값은 틱당 **6건**이다. 나머지는 오래 대기한 순서와 안정 ID 순으로 넘긴다. 대기 중 기존 경로가 유효하면 계속 이동하고, 무효면 새 판정까지 멈춘다. 15개 전장의 75편성에서 첫 타격까지 걸리는 시간, 정체 후 목표 변경, 최장 전투의 틱 처리 시간, 무승부율을 먼저 기록한다.

state = deploy(input)
