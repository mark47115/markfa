# Tavern Heros · 용병 기물 설계

다음 버전의 기물 정원은 기본 병사를 포함해 30명이다. 아래 표는 기존 편성 기준을 기록한다. [7계열 증원 규칙](faction-core-design.md) · [5단계 기물별 완편 예시](high-tier-decks.md)

현재 원정의 고용 후보는 **일반 7계열 중 무작위로 선정한 5계열**이다. 아래 전용 계열 규칙은 여기에 선택한 대장의 계열 1개를 더하는 설계다. 일반 계열마다 두 기믹이 있으며, 같은 자원이나 행동을 서로 다른 방식으로 쓴다.

## 일반 계열 7개

| 계열 | 구성 |
| --- | --- |
| 숲의 수호자 | 엘프와 드루이드 |
| 무쇠 망치단 | 드워프 |
| 송곳니의 자손들 | 수인 |
| 황혼 기사단 | 인간 기사 |

송곳니의 자손들과 호드 군단은 별개의 일반 계열이다. 각 계열은 기믹 두 개와 기물 14종을 갖는다. 기믹별 7장 모두 같은 계열의 일반 고용 후보에 들어간다.

## 런 시작과 고용 후보

1. 출정 대장을 정하고 런을 시작한다.
2. 일반 계열 7개 중 5개를 **중복 없이** 무작위로 선정한다. 첫 선술집 진입 전에 결과를 보여 주고, 그 런이 끝날 때까지 선정 결과를 유지한다.
3. 선술집은 선택된 5계열에서 현재 레벨로 열린 등급의 기물을 제시한다.
4. 후보 교체와 로언의 공개 징집도 같은 계열·등급 범위에서 다시 뽑는다. 계열 선정 결과는 원정에 저장한다.

확장팩 기물과 확장팩 추첨은 런 규칙에서 제거한다. 첫 구현 기준으로 일반 계열 선정 수는 5개다.

### 대장 전용 계열 · 설계

대장 10명은 각각 핵심 능력 하나와 전용 계열 하나를 갖는다. 전용 계열은 대장별 1·3·5등급 기물 한 장씩으로 구성된다. 전용 계열의 기물은 해당 등급에서 일반 계열과 같은 고용 테이블 후보로 더해진다. 예를 들어 강철 군단이 추첨되지 않은 런에서도 정비공 토린을 장착하면 회랑 작업대 기물이 등장할 수 있다. [대장 10명과 전용 기물 30장](captain-roster.md)

## 능력으로 만드는 시너지

- 기물 한 장은 고용·배치 단위다. 원본 2~4명과 영구 증원을 합쳐 최대 4명이 출전한다. 카드에는 **기물 효과**의 발동 시점·대상·결과와 축복 및 변신 상태를 적는다. **소속 유닛**에는 편성 수, 기본 능력치와 고유 스킬을 별도로 적는다.
- 기믹 하나로 덱을 구성할 수 있도록 소모형이 조건을 열고, 생산형이 유닛을 늘리며, 성장형이 여러 라운드의 성과를 쌓는다. 세 역할은 기획 용어다. 각 기물의 고용 후보와 시너지는 계열·등급·카드 조건을 따른다. [기믹별 세 역할](faction-mechanics.md)
- 일곱 계열의 기믹 14개와 최고 기물의 일반·황금 효과는 [계열별 기믹 설계](faction-mechanics.md)에 정리했다. [등급별 98장 기물과 유닛 효과](faction-roster.md) · [기믹 밸런스 QA](faction-balance.md) [이전 기물별 능력과 예시 편성](../archive/mercenary-design-initial.md)

## 황금 기물

일반 계열에서 얻은 같은 기물 세 장이 내 덱에 모이면 자동으로 **황금 기물 한 장**으로 합쳐진다. 내 덱 6칸과 막 고용한 한 장을 기물 ID로 확인한다. 현재 변신 형태나 강화 수치는 ID를 바꾸지 않는다.

| 항목 | 첫 설계 기준 |
| --- | --- |
| 합성 시점 | 세 번째 기물을 얻는 즉시 합성한다. 이미 두 장을 보유했다면 빈자리가 없어도 한 번의 고용으로 합칠 수 있다. |
| 배치 | 보유하던 재료 중 슬롯 번호가 가장 낮은 자리를 사용하고, 사용한 다른 재료 슬롯은 비운다. |
| 일반 황금 효과 | 카드에 적힌 강화량, 피해량, 생성량처럼 배율을 적용할 수치가 보통 2배가 된다. 발동 횟수, 대상 수, 비용, 조건은 카드에 따로 쓰인 값을 적용한다. |
| 상위 황금 효과 | 카드에 별도 황금 능력을 정의한다. 기존 능력에 효과를 더하거나 효과를 바꾼다. 이 경우 카드에 적힌 황금 능력을 사용한다. |
| 소속 유닛 | 황금 카드가 편성이나 유닛 능력치에 주는 보너스는 카드별로 지정한다. 유닛의 기본 능력치와 고유 스킬은 유닛 정의에서 관리한다. 기존 단일 유닛 프로토타입의 공격력·체력 2배는 해당 프로토타입의 테스트값이다. |
| 합성 시 성장과 증원 보존 | 축복은 세 재료의 중첩 수를 18까지 합산한다. 장비·전리품·전용 성장 등은 항목별 최댓값을 이어받는다. 영구 증원은 가장 많이 보유한 재료 한 장의 편성을 네 자리 한도 내에서, 생산 이력은 재료 전체에서 가져온다. 증원 수가 같으면 낮은 재료 슬롯을 사용한다. 형태는 결과 슬롯의 재료를 따르고 황금 카드에 별도 형태가 있으면 그 형태를 적용한다. |

선술집에서 중간 성장형의 기록을 같은 기믹의 5등급 성장형에 옮길 수 있다. 기믹별 런 1회이며 기록을 받은 만큼 기존 기물에서 차감한다. 합성과 별개의 선택이다. [성장·계승 판정](faction-mechanics.md#성장계승)

세 번째 기물을 얻을 수 있는지, 합성 재료와 결과 슬롯을 함께 확인한 뒤 한 번에 반영한다. 구매로 세 번째 장을 얻으면 고용과 합성이 각각 한 번 발생한다. 합성에 쓰인 재료는 판매·사망·이동 효과를 발동하지 않는다. 황금 상태는 그 런 동안 유지된다. 대장 전용 기물은 첫 테스트에서 기본 형태로 운용한다. [대장 전용 기물](captain-roster.md)

## 선술집과 핵심 기물 계약

일반 고용은 선술집 레벨 1~5에 따라 테이블 3·4·4·5·6개를 사용한다. 일반 기물, 대장 전용 기물과 핵심 기물 계약의 구매가는 3골드다. 핵심 기물 계약은 이번 런의 일반 계열 중 계약 대상인 5등급 기물을 선술집 5레벨, 11라운드 이후에 런당 한 번 제시한다. 새로 추가된 2·4등급 주력과 보조 기물은 각 등급에서 일반 고용으로 등장한다. 5등급 계약 대상은 개별 명단에서 지정한다.

첫 검토에서는 일반 추첨에 중복이 있는지, 대장 전용이 따로 추가되는지, 새로고침과 레벨업에도 계열 구성이 유지되는지 확인한다. [새 선술집과 내 덱](../index.html#prep-demo) · [원정과 선술집 규칙](run-rules.md)
