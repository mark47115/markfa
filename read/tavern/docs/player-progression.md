# 플레이어 레벨과 원정 특성

원정을 마치면 전투 결과를 플레이어 경험치로 정산한다. 레벨업할 때마다 상점 코인을 받고, 특정 레벨에서 외형 보상과 선택형 특성이 열린다. 새 원정에 들어갈 때 특성 하나를 고르거나 기본 전력으로 출정한다.

## 경험치 정산

| 조건 | 경험치 |
| --- | ---: |
| 전투 결과가 확정된 라운드당 | 5 XP |
| 승리한 라운드당 추가 | 3 XP |
| 4·8·12라운드 승리 시 각각 추가 | 8 XP |
| 15라운드 최종 승리 시 추가 | 30 XP |

- 침식 100%, 15라운드 결과 또는 원정 포기가 확정되면 마친 전투를 합산한다. 원정을 저장하고 나가면 이어하기로 진행한다. 전투가 시작되기 전이나 진행 중인 라운드는 결과가 확정될 때 점수를 기록한다.
- 정산한 원정 ID와 갱신한 누적 XP·코인을 함께 저장한다. 게임을 다시 열거나 결과를 다시 읽을 때 동일 원정의 지급 기록을 확인한다.
- 첫 8라운드에서 모두 패배하면 침식 100%로 종료되고 40 XP를 얻는다. 첫 8라운드에서 6승 2패이며 4·8라운드를 모두 이겼다고 가정하면, 해당 시점까지 74 XP를 모은다. 15라운드 전승은 174 XP다.

## 레벨업 보상

플레이어는 Lv. 1에서 시작한다. 다음 레벨에 필요한 경험치는 **40 + 10 × (현재 레벨 − 1)**이다. 초기 상한은 Lv. 20이며, Lv. 20까지 누적 2,470 XP가 필요하다. 한 원정에서 여러 레벨을 오르면 도달한 레벨의 보상을 모두 지급한다.

| 도달 레벨 | 누적 XP | 추가 보상 |
| --- | ---: | --- |
| 모든 레벨업 | 레벨별 필요 XP 합계 | 상점 코인 20개 |
| Lv. 2 | 40 | 방패 근무, 선봉 돌격 |
| Lv. 4 | 150 | 후열 엄호 |
| Lv. 5 | 220 | 프로필 테두리 **변경의 증표** |
| Lv. 10 | 720 | 선술집 간판 **등불지기 간판** |
| Lv. 15 | 1,470 | 프로필 칭호 **침입로 봉쇄자** |
| Lv. 20 | 2,470 | 프로필 테두리 **황동 원정대** |

Lv. 20까지 코인 380개를 지급한다. 경험치 속도와 보상 수량은 첫 밸런스 수치로 정했다. 대장 팩·조각은 기존 원정과 대장 성장 보상이며, 선술집 골드는 원정마다 충전되는 자원이다. 외형 보상은 코드에서 도달 레벨로 해금 자격을 판정하며, 외형 아트와 장착 화면은 별도로 연결한다.

## 선택형 특성

| 특성 | 해금 | 전투 시작 효과 | 비용 |
| --- | --- | --- | --- |
| 미장착 | Lv. 1 | 기본 편성으로 전투 | 없음 |
| 방패 근무 | Lv. 2 | 전열 첫 아군의 시작 보호막 +2 | 같은 유닛의 공격력 −1 |
| 선봉 돌격 | Lv. 2 | 전열 첫 아군의 공격력 +1 | 같은 유닛의 최대 체력 −1 |
| 후열 엄호 | Lv. 4 | 후열 첫 아군의 시작 보호막 +1 | 전열 첫 아군의 최대 체력 −1 |

- 출정 전 장착한 특성을 원정 ID에 기록하고, 같은 원정을 이어할 때 그 특성으로 재개한다. 전투마다 고른 진형과 원본 편성을 읽어 다시 적용한다. 같은 전투를 재현할 때 원본 능력치에서 계산한다.
- 대상은 전열·후열의 출전 순서에서 첫 아군 유닛이다. 각 특성은 이득과 비용을 함께 계산한다. 해당 열이 비어 있거나 비용을 빼면 공격력이나 최대 체력이 1 미만으로 내려갈 경우 해당 전투는 기본 편성으로 진행한다.
- 보호막은 시작 보호막에 합산한다. 최대 체력 비용은 이번 전투 동안 적용되며, 승패와 상관없이 전투를 마치면 다음 전투는 원본 편성에서 새로 계산한다.

## 적용 화면

Unity의 **Tavern Heros → R01A 첫 균열 씬 열기**에서 전투 화면 왼쪽의 플레이어 레벨과 XP를 확인한다. 전투 시작 전 **특성**을 누르거나 T를 눌러 잠금과 장단점을 확인하고 선택한다. 첫 웨이브의 실제 승리에서 8 XP, 패배·무승부에서 5 XP를 지급한다. 레벨업하면 상점 코인이 함께 정산된다. R01A는 한 웨이브가 끝날 때마다 정산하는 전투 시험 경로다.

Windows 검증 빌드는 `E:/My project/Builds/Windows-R01A-Progression/TavernHeros.exe`다. Windows 플레이어를 배치 모드로 실행해 누적 32 XP의 계정이 첫 웨이브 승리 후 **Lv. 2·40 XP·코인 +20**으로 정산되는 것을 확인했다. 방패 근무 사전 장착 시험에서는 46틱에 승리하고 8 XP를 받았다. 시험 계정은 실행 중 메모리에 두었고, 결과와 전투 기록은 `E:/My project/Logs/NativeCapture/R01A-Progression/`에 있다.

15라운드 원정의 누적 정산 규칙과 특성 적용은 Unity 공용 코어에 있다. 15라운드 진행, 홈 프로필, 상점 잔액을 Unity 전투와 이어 주는 화면 연동은 남아 있다. 4대4·100대100 훈련은 연습용 경로다.

## 밸런스 QA 3회

| 회차 | 범위 | 결과 |
| --- | --- | --- |
| 1 | XP, 보상, 해금, 중복 정산 | 레벨 경계 19곳, 전패·전승·무승부, 3레벨 동시 상승, 최대 레벨과 같은 원정 재정산을 검증했다. |
| 2 | 같은 편성으로 특성 3종과 미장착 비교 | 360개 편성, 1,440전에서 후열 엄호의 3대3 승률이 **50.8% → 60.8%**로 올랐다. 후열 시작 보호막을 +2에서 +1로 조정했다. |
| 3 | 별도 편성에서 조정값과 첫 웨이브 회귀 검증 | 960개 편성, 3,840전을 재실행했다. 특성별 전체 승률 변화는 **−0.31~−0.10%p**였다. 1대1·3대3·4대4 집단에서 가장 큰 절대 편차는 **3.44%p**였다. |

3회차의 미장착 승리는 459/960이다. 방패 근무 456/960, 선봉 돌격 458/960, 후열 엄호 458/960이다. 생성 편성을 15개씩 묶어 특성마다 64개 원정 결과를 정산했을 때, 평균 XP는 미장착 84.28, 방패 근무 83.97, 선봉 돌격 82.67, 후열 엄호 83.17이었다.

R01A는 미장착 24틱 승리, 방패 근무 46틱 승리, 선봉 돌격 24틱 패배, 후열 엄호 24틱 승리로 재현했다. R01A에서 후열 엄호는 후열 유닛이 없어 효과가 적용되지 않는다.

전투 QA는 Unity가 사용하는 AutoBattle 코어에서 전열·후열과 능력치가 다른 생성 편성을 같은 초기 조건으로 맞춰 비교했다. 실제 15라운드 경제·예언·75개 적 편성과 연결했을 때의 클리어율 검증은 진행 화면 연동 뒤에 수행한다.

```powershell
& ./workspace/2026-11-19_cavern-heros-25169da3/qa/player-progression.ps1 1
& ./workspace/2026-11-19_cavern-heros-25169da3/qa/player-progression.ps1 2
& ./workspace/2026-11-19_cavern-heros-25169da3/qa/player-progression.ps1 3
```

2회차 명령을 다시 실행하면 현재 적용된 조정값으로 2회차 표본을 재검증한다. 조정 전 결과는 위 표에 기록했다. [원정 규칙](run-rules.md) · [Unity 첫 전투](unity-battle.md)
