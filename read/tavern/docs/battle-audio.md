# 전투 사운드

전투음은 유닛의 동작을 전달하고, 음악은 지역이 외신에게 잠식되는 흐름을 잡는다. [유닛별 효과음과 배경음악 비교](../battle-audio.html)

## 공격과 피격

| 들리는 순간 | 소리 |
| --- | --- |
| 석궁 장전과 발사 | 조용한 걸쇠 → 짧은 발사음 → 명중한 표면의 별도 충격음 |
| 활·투석구·투창 | 시위가 튕기는 소리, 돌이 빠지는 마찰음, 창이 지나가는 바람음을 구분 |
| 근접 타격 | 검날은 짧고 날카롭게, 망치는 낮고 무겁게, 방패는 둔한 판의 울림 |
| 공허군 | 진드기의 튀는 갑각, 삼키는 자의 두 번 닫히는 턱, 공허 포격의 낮은 공명 |
| 방어·스킬 | 보호막 흡수·파쇄, 치유, 발전기, 징 신호는 별도 소리 |

무기 종류와 피격 재질에 52개 효과음을 지정했다. 검의 베기와 찌르기, 도끼의 내려치기와 횡베기는 각각 같은 파일을 사용한다. 석궁 장전·발사·명중은 동작에 맞춰 분리한다. 취소된 공격과 빗나간 투사체는 명중음을 내지 않는다.

## 음악과 믹스

| 라운드 | 제목 | 편곡 |
| --- | --- | --- |
| 1–6 | 초소 너머 | D장조, 덜시머 선율과 짧은 나무 피리 응답 |
| 7–12 | 바위 아래 맥 | B단조, 첼로와 낮은 현을 중심으로 편곡 |
| 13–15 | 균열 앞의 마지막 진형 | D단조, 덜시머를 낮추고 낮은 첼로로 긴장을 유지 |

세 곡은 각 40초 루프다. 홈의 「변경의 벽난로」와 같은 덜시머·첼로·나무 피리·류트·저음 현·현악 합주·가죽북을 쓴다. 균열곡에서 호른과 합창, 추가 큰북을 빼고, 징과 갑각 파쇄 효과음의 날카로운 대역과 잔향도 줄였다.

같은 효과음이 60ms 안에 여러 번 요청되면 화면 위치를 평균 내고 한 번만 재생한다. 두 번이 겹치면 단발보다 −3dB, 네 번이면 −6dB로 낮춘다. 다른 무기의 소리는 각각 재생된다. 기본 공격 6채널과 중요 효과 3채널을 사용하며, 주요 스킬이나 보호막 소리에 음악을 최대 5.5dB 낮춘다. 음악과 효과음 볼륨은 설정에서 따로 조절한다.

## 소스와 검증

- 직접 합성한 48kHz 16비트 WAV를 사용한다. 음악은 스테레오, 효과음은 모노다. 기존 타이틀 작곡 도구를 재사용해 새 곡을 편곡했다. 외부 음원과 샘플은 사용하지 않았다. [생성 스크립트](../qa/render-battle-audio.py)
- 밀집 비교 믹스에서 효과음 요청 264개를 120개로 줄였다. 마지막 3초의 피크는 −9.88dBFS에서 −15.57dBFS로 낮아졌다. [유닛·스킬 연결표](../media/battle-audio/v2/profiles.json) · [파일 해시와 실측값](../media/battle-audio/v2/manifest.json)
- 게임 코드의 그룹 처리, 방향 평균, 감쇄, 다른 무기 분리, 일시정지와 음소거를 검증했다. 비교 WAV에는 같은 묶음 규칙을 적용했다. Android 실기기 청취는 별도로 남아 있다. [이전 밀집 믹스](../media/battle-audio/v1/preview/rift-mix.wav)
