# Tavern Heros 캐릭터 이미지 프롬프트

[V3 캐릭터 시트](../media/art-direction/character-style-v3.png)를 첨부하고, 아군 또는 공허 적의 기본 프롬프트를 복사한다. 마지막 줄의 대괄호를 원하는 캐릭터 설명으로 바꾼다. 한 이미지에는 캐릭터 한 개체의 전신을 그린다. 목록의 장비와 색 배치는 외형 시안이다.

## 아군 용병 기본 프롬프트

```text
Cavern Heros용 오리지널 판타지 아군 용병 한 종의 전신 도트 스프라이트 레퍼런스를 그려줘. 첨부한 V3 시트의 위쪽 세 캐릭터를 픽셀 밀도, 명암, 2등신 비율의 기준으로 사용해.

첫 단계부터 하나의 정사각 픽셀 격자에서 작화해. 멀리서도 보이는 큰 픽셀 덩어리, 계단형 외곽, 기본색과 그림자 면, 작은 하이라이트를 사용해. 부드러운 그라데이션, 흐린 외곽, 후처리 픽셀화, 잔무늬와 과한 광원 효과는 제외해.

머리는 전체 높이의 절반에 가깝고, 몸은 둥글고 넓으며 손발은 짧아. 단추 같은 눈과 밝고 친근한 표정을 넣어. 큰 장비 하나가 역할을 설명하게 해. 입력한 계열의 구성 종족과 장비 설명을 외형에 반영해. 낮은 등급과 높은 등급은 대표 장비의 외곽과 색 면으로 구분해.

정사각 캔버스, 살짝 내려다보는 3/4 게임 시점, 화면 왼쪽 아래를 향한 기본 자세. 발끝과 장비가 전부 보이게 여백을 두고, 단색의 따뜻한 양피지 배경에 캐릭터 한 개체를 가운데 배치해. 글자, 이름표, 수치, UI, 소품이 놓인 바닥, 로고, 워터마크는 넣지 마.

캐릭터 외형 — [계열 이름, 구성 종족, 전투 역할, 대표 장비를 입력]
```

### 계열 구성과 이전 용병 외형 예시

새 용병의 캐릭터 설명에는 [현재 일반 계열과 종족 구성](mercenary-design.md)을 사용한다. 아래 22종은 이전 기물 명단의 외형 예시다.

| 계열 | 캐릭터 | 교체 문구 |
| --- | --- | --- |
| 강철 | 리벳 운반공 | 꿀색 눈과 청록 스카프를 한 둥근 황동 기계. 장갑 같은 두 손으로 큰 리벳 하나를 안는다. |
| 강철 | 피스톤 방패병 | 낮고 넓은 둥근 기계. 얼굴 옆에 큰 철제 앞방패, 방패 가장자리에 짧은 피스톤 하나가 드러난다. |
| 강철 | 철갑 허물 | 청록 눈이 보이는 속 빈 철갑. 겹친 어깨판과 뒤로 열린 등껍질이 대표 외곽을 이룬다. |
| 강철 | 동력 수레 | 웃는 작은 기계 얼굴이 달린 둥근 수레. 큰 바퀴 두 개와 투명한 얇은 보호막 띠를 분리해 보여 준다. |
| 강철 | 이동 주조소 | 둥근 화덕 몸통의 넓은 수호 기계. 보호용 앞판 위로 주황빛 용광로 창 하나가 보인다. |
| 이끼 | 이끼 새싹 | 짧은 뿔이 달린 민트 후드, 웃는 둥근 얼굴, 한쪽 어깨의 잎사귀 가방을 멘 작은 정찰병. |
| 이끼 | 뿌리 파수꾼 | 민트 후드 아래 둥근 얼굴이 보이는 파수꾼. 몸보다 넓은 매듭 뿌리 방패를 앞에 든다. |
| 이끼 | 포자 치료사 | 넓고 낮은 버섯 모자와 크림빛 망토. 짧은 약병 하나와 작은 포자 무늬로 치료사임을 보여 준다. |
| 이끼 | 덩굴뿔 | 잎색 후드 위로 크게 갈라진 나뭇가지 뿔 한 쌍. 작은 덩굴 장갑과 민트색 망토를 착용한다. |
| 이끼 | 고목의 심장 | 큰 나이테가 얼굴을 감싸는 아기 고목. 가슴 한쪽에 라임빛 심재, 머리 위에 둥근 잎관이 있다. |
| 망령 | 초롱 망령 | 상아색 짧은 두건 아래 작은 눈 두 점과 둥근 하단. 살구빛 초롱 하나가 떠서 몸과 간격을 이룬다. |
| 망령 | 조종지기 | 둥근 라벤더 후드와 상아색 소매. 몸통 옆에 작고 넓은 청동 종을 한 손에 든다. |
| 망령 | 안개 청지기 | 넓은 상아색 어깨 천과 짧고 둥근 몸. 가슴 앞의 작은 등불 심지가 본체와 살짝 떨어져 보인다. |
| 망령 | 빈 무덤지기 | 둥근 석판처럼 넓은 모자와 짧은 라벤더 외투. 작은 초롱 핵과 넓적한 삽이 각각 읽힌다. |
| 망령 | 그림자 행렬 | 한 기물의 전신. 크림색 가면, 짧은 라벤더 외투, 얼굴 옆에 겹치지 않는 두 개의 꺼진 종이 달린 둥근 행렬 지휘자. |
| 중립 | 여관 보초 | 따뜻한 갈색 피부, 둥근 강철 투구, 살구색 스카프. 웃는 맨얼굴 옆으로 큰 방패 하나를 든다. |
| 중립 | 돌팔매꾼 | 크림색 모자와 살구색 조끼. 팔을 몸 가까이 두고 큰 가죽 새총 하나를 잡는다. |
| 중립 | 등불 수리공 | 둥근 작업 모자와 청록색 앞치마. 손에 노란 등불을 들고, 몸에서 한 뼘 떨어진 얇은 보호막 띠가 보인다. |
| 중립 | 청동 결투사 | 작은 깃털이 달린 둥근 모자와 청동 가슴판. 가벼운 가로날 하나로 공격 쪽 외곽을 길게 잡는다. |
| 중립 | 서약 수호자 | 크림색 옷 위에 살구색 서약 천을 묶은 수호자. 넓은 세로 방패와 몸 밖의 얇은 보호막을 분리한다. |
| 중립 | 마지막 문지기 | 낮고 둥근 철제 투구와 살구색 목도리. 작은 성문을 닮은 두 짝 판형 방패 앞에 보호막 띠가 보인다. |
| 중립 | 유리날 용병 | 밝은 크림색 외투와 청회색 장갑. 큰 유리날 하나의 각진 외곽과 그 바깥의 얇은 보호막 띠가 서로 떨어져 보인다. |

## 공허 적 기본 프롬프트

```text
Cavern Heros용 오리지널 공허 적 한 종의 전신 도트 스프라이트 레퍼런스를 그려줘. 첨부한 V3 시트의 아래쪽을 비대칭 생물 외형의 기준으로 쓰고, 위쪽 아군과 같은 픽셀 밀도와 명암 단계로 그려.

첫 단계부터 하나의 정사각 픽셀 격자에서 작화해. 멀리서도 보이는 큰 픽셀 덩어리, 계단형 외곽, 기본색과 그림자 면, 작은 하이라이트를 사용해. 부드러운 그라데이션, 흐린 외곽, 후처리 픽셀화, 잔무늬와 과한 광원 효과는 제외해.

심해와 우주괴담을 닮은 기괴한 비인간 생물로 만들어. 한쪽이 무거운 몸통, 서로 다른 각도로 꺾인 관절, 특이한 눈의 위치 중 캐릭터 설명에 나온 특징을 대표 실루엣으로 삼아. 먹보라, 탁한 청회색, 짙은 청록을 큰 색 면으로 두고, 뼈색은 갈라진 갑각에, 청록 또는 병든 연두색 발광은 눈이나 핵에만 집중해. 도발은 낮고 넓은 앞판, 보호막은 몸 바깥의 끊김 없는 띠, 부활은 본체와 떨어진 작은 핵으로 읽히게 해. 캐릭터 설명에 있는 역할 신호만 사용해.

정사각 캔버스, 살짝 내려다보는 3/4 게임 시점, 화면 왼쪽 아래를 향한 기본 자세. 다리·촉수·갑각 끝이 전부 보이게 여백을 두고, 단색의 채도 낮은 연보라 회색 배경에 캐릭터 한 개체를 가운데 배치해. 기존 유명 괴물의 얼굴이나 디자인을 복제하지 말고, 피, 상처, 글자, 이름표, 수치, UI, 로고, 워터마크는 넣지 마.

캐릭터 외형 — [공허 적 목록에서 한 항목 붙여넣기]
```

## 선술집과 전장에 적용

- **선술집 시안**에는 승인된 전신 이미지를 첨부한 뒤 이 문구를 붙인다. `기물 한 장에 속한 용병 전원이 같은 원형 테이블에 둘러앉아 있다. 장비와 전체 색은 전신 이미지와 통일하고 얼굴에 작은 차이를 준다. 등급 이름이나 인원 숫자를 이미지에 직접 그리지 않는다.`
- **전투 정지 자세**는 승인된 전신 이미지를 캐릭터 참조로 붙인다. 아군과 적이 마주 보도록 필요한 방향을 지정하고, 비대칭 방패·창·갑각의 해부학적 좌우를 유지한다.
- **비교 시트**는 캐릭터 세 종을 같은 눈높이와 픽셀 크기로 가로 한 줄에 배치한다. 발이나 몸통 아래의 기준선을 맞추고 보스의 크기 차이는 남긴다. 480×270 게임 화면에 배치했을 때 이름표 없이도 실루엣과 역할을 구별할 수 있는지 확인한다.
