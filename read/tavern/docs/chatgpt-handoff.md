# Tavern Heros · ChatGPT 디자인 인수인계

**현재 작업은 도트 그림체와 선술집 화면 설계다.** 큰 픽셀이 읽히는 판타지 덱 빌딩 오토배틀러로, 2층의 대장이 1층 선술집에서 용병 기물을 고용하고 전투에 배치한다. 현재 비교 기준은 캐릭터와 선술집의 **v3 시안**이다. 엔진에서의 가독성과 조작은 후속 검증 항목이다.

## 그림체 통일 기준

| 항목 | 디자인 기준 |
| --- | --- |
| 공통 픽셀 | 큰 정사각 픽셀, 계단형 윤곽, 적은 명암 단계, 넓고 단순한 색 면. 캐릭터·가구·배경에 일관된 픽셀 밀도와 광원 방향을 적용한다. 실제 화면의 기준 해상도는 480×270이다. |
| 아군 용병 | 밝고 귀여운 2등신에 가깝게. 머리는 키의 절반에 가깝고 팔다리는 짧고 둥글다. 작은 얼굴에서도 표정이 읽혀야 한다. 방패, 뿔이 달린 이끼 후드, 태엽 장치처럼 역할을 구분할 큰 특징을 하나씩 준다. |
| 공허 적 | 크툴루풍의 기괴함을 비대칭 몸, 어긋난 관절, 여러 눈, 촉수로 표현한다. 먹보라와 어두운 청회색을 바탕으로 발광하는 눈에 대비를 준다. 픽셀의 크기와 명암 단계는 아군과 맞춘다. |
| 선술집 | 따뜻한 목재와 촛불, 약한 바닥 무늬. 용병과 고용석이 배경보다 먼저 읽히게 한다. 자연스러운 광원과 별도로 호박색 고용 선택 테두리와 청록색 내 팀 경계를 쓴다. |
| 작은 화면 | 원본 이미지가 큰 경우에도 480×270 크기에서 방패·뿔·태엽과 적의 외곽이 읽히는지 본다. 실제 스프라이트 제작 시 흐림 없이 정수 배율로 확대한다. 팔레트의 정확한 색상값과 최종 스프라이트 규격은 실측으로 정한다. |

## 선술집 화면 설계

- **카메라와 공간.** 가깝고 높은 대각선 3/4 시점. 2층 회랑의 대장, 난간, 오른쪽 계단, 회랑 아래 카운터와 1층 고용 홀의 높이 관계가 보여야 한다. v3 촬영 각도가 우선이며 프롬프트에 기록된 각도 수치는 시안용이다.
- **기물 단위.** 원형 테이블 하나는 고용 기물 하나다. 해당 기물의 유닛 **전원**이 같은 테이블에 앉고, 선택 테두리는 테이블과 의자 전체를 감싼다. 시안 속 기물당 2–3명은 좌석을 보여 주는 예시다.
- **등급 확장.** 1등급 3개, 2–3등급 4개, 4–5등급 5개. v2 배치 제안은 기존 세 그룹의 위치를 유지하며 바깥 자리를 열고 카메라를 고정하는 것이다. v3에서는 같은 방식으로 확장 가능한지 확인한다.
- **내 팀.** 하단에 7칸을 상시 표시한다. 채운 칸은 대표 도트와 구성원 수, 빈 칸은 앞으로 쓸 공간이다. v3의 3칸 채움·4칸 비움은 화면 예시다. 고용석과 내 팀은 영역, 칸 테두리, 색상으로 구분한다.
- **전투 연결.** 선술집에서 본 용병의 외곽과 역할 표시를 전투에서도 알아볼 수 있게 유지한다. 전투 전까지 고용 목록과 소유 팀의 정보가 섞이지 않도록 한다.

## 함께 저장된 디자인 스킬

압축본의 `skills/<이름>/SKILL.md`는 아래 Workspace 스킬의 원본이다. 각 스킬에서 Cavern Heros에 바로 적용할 부분을 요약했다.

| 스킬 | 현재 프로젝트에서 쓰는 방법 |
| --- | --- |
| `image-reference-workflow` | 최신 시안을 직접 참조하고 이미지마다 역할을 지정한다. 편집할 요소를 짧게 명시한 뒤 카메라·인물·조명의 변화를 비교한다. 사용한 프롬프트와 원본을 남긴다. |
| `game-ui-workflow` | 먼저 고용석과 내 팀이 전달할 정보를 정한다. 빈 칸·채운 칸·선택 상태를 각각 확인하고, 7칸의 길이와 가림 여부를 480×270에서 검토한다. |
| `game-level-design` | 대장·계단·카운터·고용 테이블의 위치와 통로를 기준 화면과 함께 기록한다. 등급별로 테이블을 추가할 때 동선과 가려짐을 비교한다. |
| `gameplay-visual-review` | 검토용 시안은 시안으로 표시한다. Unity 적용 뒤 동일 카메라와 배치 조건으로 가독성, 선택, 슬롯 갱신을 직접 확인하고 실제 캡처를 남긴다. |

Workspace에서 스킬 원본의 위치는 `.agents/skills/<이름>/SKILL.md`다. 결과 문서, 새 이미지, 프롬프트와 검토 기록은 **Cavern Heros 카드**에 저장한다. 시안은 새 버전으로 저장해 v3와 비교할 수 있게 한다.

## 다음 검토 과제

가장 먼저 **같은 v3 구도의 4–5등급 5테이블 화면**을 검토한다. 기존 세 테이블을 알아볼 수 있고, 나머지 두 테이블과 좌석까지 생겨도 대장·계단·통로·내 팀 7칸이 보이는지 확인한다. 내 팀과 고용석을 한눈에 구분할 수 있어야 한다. 사용자 승인 여부와 Unity 적용 검증은 각각 기록한다.

이미지 제작 요청이 오면 기존 선호대로 **ChatGPT의 Higgsfield 연결**을 사용한다. 최신 파일을 참조로 넣고, 모델과 설정이 계정의 무제한 체험에 적용되는지 생성 전에 확인한다. 무제한 사용을 전제로 요청받았다면 일반 크레딧으로 자동 전환하지 않는다.

