## 실제 게임 화면에서 본 정보 배치

| 게임 | 화면에서 확인한 요소 | Cavern Heros에 가져올 점 |
| --- | --- | --- |
| **하스스톤 전장** | 고용 단계의 화면 위쪽에 밥과 레벨업·새로고침·동결이 모인다. 구매할 하수인은 그 아래에 있고 내 진영은 화면 아래에 있다. 버튼 바로 옆의 숫자로 비용을 읽는다. [고용 1턴 캡처](https://youre.outof.games/media/uploads/8a/de/8ade5941-b750-48c8-a771-d629cfe53637/turn_1.png) · [블리자드 고용 단계 안내](https://news.blizzard.com/en-gb/article/23156373/introducing-hearthstone-battlegrounds) | 상점과 내 팀을 위·아래로 구분한다. PC HUD의 레벨업 버튼 옆에 다음 해금 내용을 두고, 실제 게임에 경제를 연결하면 액션의 골드 비용도 같은 위치에서 읽게 한다. |
| **스타 선술집 전투 · 아몬 도전** | 실제 플레이 캡처에서 같은 기물에 속한 유닛이 번호가 있는 한 구역에 모인다. 왼쪽 아래에는 선술집 등급과 업그레이드 비용이 붙어 있다. [대만판 아몬 도전 플레이 캡처](https://truth.bahamut.com.tw/s01/202511/forum/3037/da987dedcabe061a436a6fa41206c873.JPG) | 테이블과 둘러앉은 용병 전원이 하나의 선택 단위다. 테이블마다 이름·등급·인원 정보를 하나의 영역에 모은다. 테이블 전체에 선택 테두리를 사용하고, 모바일 입력 영역은 의자와 테이블까지 포함하는 것을 기준으로 삼는다. |
| **롤토체스** | Riot의 PC 자료에서는 레벨·경험치와 등급별 확률이 같은 줄에 있고 경험치 구매·새로고침은 상점 카드 옆에 붙는다. 모바일 자료에서는 보드 가까이에 큰 모서리 버튼을 두고, 상점은 필요할 때 열어 공간을 확보한다. [Riot PC 상점 화면](https://teamfighttactics.leagueoflegends.com/en-au/news/game-updates/tft-interface-update/) · [Riot 모바일 화면](https://teamfighttactics.leagueoflegends.com/en-gb/news/riot-games/teamfight-tactics-mobile-update/) | PC와 모바일 모두 현재 레벨 옆에서 등장 가능 등급을 읽을 수 있게 한다. 확률은 밸런스가 정해지면 상세 정보에서 보여 준다. 모바일 기본 화면에는 등급 범위와 다음 해금 요약을 둔다. |
| **클래시 로얄** | 세로 전투 화면에서 전장이 가운데 대부분을 차지하고, 반복 조작하는 카드 4장은 아래에 붙는다. 시간과 전장 정보는 위쪽에 남는다. [Supercell의 세로 전투 이미지](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource211/v4/9f/c9/e8/9fc9e8b0-3d9e-5782-2d88-288b6c22dbb5/ad38c4ab-3578-4f01-b9e6-e3e18e215dcd_CR_AppleStore_picture03_1284x2778.jpg/1284x2778.png) · [App Store 게임 페이지](https://apps.apple.com/us/app/clash-royale/id1053012308) | 모바일 액션을 엄지에 가까운 아래쪽에 둔다. 하단 패널은 내 팀 7칸을 한 줄에 표시하고, 바로 아래에 레벨업 버튼과 다음 해금 정보를 둔다. |

전장과 롤토체스 화면은 각 문서가 공개된 시점의 UI 레퍼런스다. 스타 선술집은 커뮤니티에 게시된 아몬 도전 실플레이 캡처를 기준으로 삼았다.

## 수정 시안의 크기 기준

| 항목 | PC 가로 · 기준 너비 1280px | 모바일 세로 · 기준 너비 360~450px |
| --- | --- | --- |
| 선술집 상태 | 상단 한 줄. 현재 레벨 20px, 테이블 수와 등급 범위 16px | 상단 두 줄. 현재 레벨 22px, 테이블 수와 등급 범위 16px |
| 레벨 올리기 | 상단 오른쪽, 높이 40px. 다음 해금 요약을 버튼 옆에 표시 | 하단 오른쪽, 높이 48px와 글자 17px. 다음 해금 요약은 왼쪽에 표시 |
| 고용 테이블 | 5개일 때 뒤 2개·앞 3개. 등급 라벨 14px | 5개일 때 위부터 2·2·1. 작은 화면에서도 등급 라벨 약 14px 이상 |
| 내 팀 | 46px 초상화와 최대 너비 680px의 중앙 하단 패널 | 44px 슬롯 7개를 한 줄로 표시. 하단에 안전 여백 확보 |

새 PNG는 Lv. 1과 Lv. 4의 화면 비교용이다. 고용, 골드 소비와 슬롯 조작을 실제 게임에 연결할 때는 테이블 전체의 선택 영역, 버튼의 비활성 상태, 길어진 한국어 이름의 줄바꿈을 함께 검증한다.
