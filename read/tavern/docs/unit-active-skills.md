# Tavern Heros · 아군 유닛 액티브 스킬

일반 기물 소속 유닛 14명에 지원 7종·공격 7종을 하나씩 배정한다. 기본 공격과 패시브를 유지하며 조건이 맞으면 자동 시전한다. 수치와 타이밍은 첫 플레이테스트 기준이다. [기물과 소속 유닛](faction-roster.md) · [전투 판정](combat-design.md) · [이펙트 재생](../combat-vfx.html)

다음 버전은 일반·대장 전용 병종과 공허군 전체에 전투 스킬을 배정한다. [새 병종별 스킬과 최종전 규칙](unit-skill-rules.md)

## 시전 공통 규칙

- 시간 표기는 **첫 사용 가능 시점 / 재사용 대기시간 / 시전 시간** 순이며 모두 초다. 첫 사용 가능 시점 이후 유효한 조건을 만족하면, 진행 중인 기본 공격 동작이 끝난 뒤 시전을 시작한다. 시전 중 이동과 기본 공격의 준비도 진행을 멈추고, 시전이 끝나거나 중단되면 재개한다. 기존 패시브의 발동과 이미 발사한 공격은 계속 판정한다.
- 대상이 없으면 준비 상태를 유지한다. 시전 시작 시 대상이나 범위 중심을 고정한다. 대상 지정형은 완료 시 고정 대상의 생존과 범위를 다시 확인한다. 위치 지정형은 고정된 바닥 범위에 완료 시점에 있는 대상에게 효과를 적용한다. 같은 거리나 우선순위에서는 출전 슬롯, 소속 유닛 편성 순번 순으로 고른다.
- 확정 전에 시전자가 퇴장하거나 행동불능이 되면 효과가 취소된다. 시전이 완료되거나 중단된 시점부터 재사용 대기를 센다. **전투 1회** 스킬은 시전을 시작할 때 사용 횟수를 소모하고, 부활 뒤에도 그 기록을 유지한다.
- 거리와 반경은 전장 월드 단위이며 바닥에서 유닛 중심 사이의 거리로 잰다. 지원 대상은 기본 편성의 생존 아군이다. 동력 분배와 불씨 산탄은 명시된 영구 증원 유닛을 읽는다. 시전자 자신이 대상에 포함될 때는 스킬에 표기한다.
- 피해량은 표의 고정값에 대상의 기존 방어·보호막 판정을 적용한다. 범위 한 번에 피해 사건 ID 하나를 사용한다. 스킬 피해는 기본 공격의 첫 적중 보너스를 소모하지 않는다. 추격 기여와 사냥 표식의 최종 퇴장은 다음 선술집 정산에 쓸 전투 기록으로 남긴다.
- 같은 이름의 유닛 스킬이 주는 보호막·버프·디버프는 큰 수치 한 번만 적용한다. 같은 수치의 재시전은 지속시간을 갱신한다. 서로 다른 액티브가 같은 유닛의 공격속도 또는 이동속도에 같은 방향으로 효과를 주면 가장 강한 하나를 적용한다. 기물 황금 효과는 표의 스킬 피해·횟수·재사용 시간을 바꾸지 않는다.

## 플레이테스트에서 확인할 항목

1. 같은 시드와 편성에서 액티브를 켜고 끈 전투를 비교한다. 지원기는 실제 흡수량·회복량과 추가 기본 공격 수를, 공격기는 피해와 적중 인원을 기록한다. 시전으로 미뤄진 기본 공격도 같이 확인한다.
2. 단일 보스·밀집 적·산개 적 상황에서 첫 시전과 완료 시간을 비교한다. 표시한 범위에 새로 들어온 적, 범위에서 빠져나간 적, 도중에 쓰러진 대상과 시전자를 각각 시험한다.
3. 부활, 범위 동시 퇴장, 황금 합성, 같은 스킬을 지닌 기물 두 장을 넣어 사용 횟수와 상태 중복을 확인한다. 재생 1배와 2배로 같은 시전 기록과 피해 판정이 나오는지 비교한다.
