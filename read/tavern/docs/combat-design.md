# Tavern Heros 전투 설계

선술집에서 고른 배치가 첫 교전의 모양을 바꾼다. 앞에 둔 용병이 누구의 공격을 받았는지, 어느 후열 유닛이 먼저 공격했는지, 대장이나 권능이 어느 순간 전투를 바꿨는지가 화면에서 읽혀야 한다. 전투는 실시간으로 자동 진행하며 유닛 선택은 정보 확인에 사용한다. 아래 수치는 첫 플레이테스트를 위한 제안값이다.

## 카메라와 전장

가로 전장에서는 아군이 화면 왼쪽, 공허 군단이 화면 오른쪽에서 중앙을 향한다. 높은 시점으로 바닥의 앞뒤 거리, 실루엣, 공격의 출발점과 도착점을 함께 보여 준다. 초기 상하 구도의 참고 화면은 공식 프레스 키트의 `BlizzCon 04`와 `Co-op 02`다. [현재 가로 전장](../battle-maps.html) · [블리자드 공식 게임플레이 스크린샷](https://blizzard.gamespress.com/en/BlizzCon-2015-StarCraft-II-Legacy-of-the-Void-press-kit)

| 항목 | 첫 구현 기준 |
| --- | --- |
| 투영 | 지면 기준 하향 55°의 가로 전장. 가로축은 전투 진행 방향 `−z`, 화면 위·가운데·아래의 전술 열은 `x`다. 가로 평면과 같은 좌우 위치를 유지한다. |
| 프레이밍 | 전장 20×16 월드 단위, 전장 렌더는 480×270 기준으로 시작한다. 교전면을 한 화면에 담고 벽이나 기둥이 유닛에 겹치면 외곽 장식의 높이를 줄인다. |
| 카메라 동작 | 출전부터 결과까지 시점을 고정한다. 조준·선택은 바닥 외곽선과 상세 패널로 표시한다. 보스 분열 중에도 같은 구도를 유지해 호위와 분열체의 위치를 비교할 수 있게 한다. |
| 가로 모바일과 PC | 같은 카메라 방향과 진형을 유지하고 전장 전체를 표시한다. 적 정보와 재생 조작은 전장 외곽의 안전 영역에 두고, 모바일의 짧은 높이에서도 주요 버튼에 44px 이상의 누르는 영역을 확보한다. |
| 비교 기준 | 45°에서 캐릭터의 정면이 더 보이는지, 65°에서 전후열과 겹친 체력바가 더 잘 분리되는지 비교한다. 55°를 기본안으로 두고 같은 편성으로 비교한다. |

## 출전 배치

- **내 덱의 6칸과 진형**을 출정 시 그대로 사용한다. 2열 종대는 앞에서부터 `1·2`, `3·4`, `5·6` 세 줄이고, 2열 횡대는 `1·2·3`, `4·5·6` 두 줄이다. 기물별 기본 편성은 2~4명이며 영구 증원을 합해 최대 4명이다. 기물 기준점을 중심으로 근접은 앞, 원거리·지원은 뒤에 놓고 같은 역할은 유닛 편성 순서대로 가로로 벌린다.
- 시험 좌표는 전장 중심 `(0, 0)`, 오른쪽 `+x`, 아군 쪽 `+z`다. 종대는 `x=−3.2, +3.2`, `z=+2.6, +4.5, +6.4`, 횡대는 `x=−5.8, 0, +5.8`, `z=+3.1, +5.7`이다. 적 전후열은 `z=−3.2, −5.8`, `x=−5.8, 0, +5.8`이다.
- `출발 열`, `출전 슬롯·편성 순번`, `전투 중 실제 위치`를 기록한다. 라크의 ‘같은 열’은 출발 기준점이 속한 좌·중·우 열, 기물의 ‘이웃’은 선택한 그리드에서 상하좌우로 붙은 칸이다. 사거리와 거리 기반 효과는 실제 위치를 사용한다. 열 경계는 `x=−3.75, +3.75`다. 심해 파동은 3초에 실제 위치로 위험 열을 고정하고 4초에 각 위험 열에서 적 쪽으로 가장 앞선 아군을 판정한다. 4초에 빈 열이면 빗나간다. [적 배치와 권능](enemy-character-design.md) · [대장 패시브](captain-roster.md)

## 자동 교전

타깃 선정, 충돌과 이동, 틱 안의 피해·부활·분열 순서는 [유닛 전투 AI와 오토배틀 알고리즘](combat-ai.md)을 따른다.

| 단계 | 판정 |
| --- | --- |
| 출정 확정 | 대상·형태·배치·비용을 확정한다. 원본과 영구 증원을 배치하고 이번 전투용 보너스를 적용한다. 위치·대상을 기록한 뒤 시작 권능을 처리한다. |
| 조준과 접근 | 양측 모두 상대 진영을 향해 전진을 시작한다. 사거리 안의 생존 도발 대상이 기본 공격에 우선한다. 일반 근접은 접근 가능한 적 전열을 먼저 본다. 일반 원거리는 사거리 안의 가장 가까운 적을 조준하고, 사거리 안에 적이 없으면 가까운 접근 가능 대상까지 이동한다. 동률은 출발 전열 → 왼쪽 → 슬롯·편성 순번이다. 스킬·권능의 명시 대상은 각 규칙을 따른다. |
| 이동과 공격 | 근접은 대상 둘레의 빈 공격 위치를 찾아 접근하고, 원거리는 사거리에 닿으면 멈춰 준비한다. 아군이 길을 막으면 빈 공격 위치를 다시 찾는다. 대상이 사라지거나 길이 막히면 가능한 다른 대상을 고른다. 준비 중 대상이 유효 범위를 벗어나면 공격을 취소하고, 발사한 투사체는 원래 대상이 유효할 때 명중한다. |
| 유닛 액티브 | 사용 시점과 대상 조건이 맞으면 유닛이 직접 시전한다. 진행 중인 기본 공격 동작을 먼저 마치고, 시전하는 동안 이동과 기본 공격 준비를 멈춘다. 시전 중 확정한 대상·범위, 중단, 재사용 대기는 스킬 공통 규칙을 따른다. [유닛 액티브 14종](unit-active-skills.md) |
| 피해와 후속 효과 | 기본 피해를 계산하고 첫 피해 경감 → 보호막(만료가 빠른 임시 보호막부터) → 에다 등 남은 체력 피해 경감 → 체력 감소 순으로 처리한다. 범위 피해 전체를 적용한 뒤 나린의 응급 처치, 부활, 최종 퇴장과 적의 분열을 처리한다. 피해·생존·처치 기록은 다음 선술집의 기물 효과 정산에 사용한다. |
| 종료 | 후속 부활·분열을 해결한 뒤 아군이 전멸하면 패배다. 양쪽 동시 전멸에도 적용한다. 아군이 남고 적을 전멸시켰으면 승리다. 시험에서는 30초에 그 틱까지 예약된 사건을 처리하고 양측이 남아 있으면 무승부다. 보스 본체가 쓰러져도 분열체와 호위를 쓰러뜨릴 때까지 계속한다. |

- 첫 실험은 **20Hz 고정 틱**, 일반 이동 **초당 2.8 단위**, 근접·원거리 사거리 **0.9·4.6 단위**로 시작한다. 사거리는 두 충돌 반경 사이 거리로 잰다. 기본 공격은 근접 **22틱 중 준비 7틱**, 원거리 **28틱 중 준비 9틱**을 쓴다. [경로와 기본 공격 시간](combat-ai.md) · [기물과 소속 유닛](faction-roster.md)
- 시드, 입력 편성, 슬롯 번호, 사건 처리 순서를 고정하면 결과와 사건 기록을 재현할 수 있어야 한다. 한 틱의 적중 대상은 피해 적용 직전에 확정한다. 그 틱에서 서로 치명타를 맞으면 양쪽 타격을 모두 처리한다. 새 대상 선택은 후속 효과와 퇴장을 처리한 다음 시작한다. 전투 재생 배속은 기록 재생에만 적용한다.
- 아군 전멸 시 패배 라운드에 따라 침식이 오른다. 100%면 런이 종료된다. 다음 라운드가 열리면 사망한 유닛을 복구하고 기존 덱과 진형을 유지한다. 15라운드 승리로 원정을 완료한다. [침식 증가와 복구 규칙](run-rules.md)

## HUD와 결과

| 화면 | 표시와 조작 |
| --- | --- |
| 출전 직전 | 상단에 라운드·침식도·적 권능, 전장에는 선택한 6칸 진형과 적의 전후열 출발 구역. 기물을 선택하면 소속 유닛 위치를 강조한다. |
| 진행 중 | 상단에는 시간·권능, 하단에는 일시정지·1×/2×·전투 기록. PC 클릭 또는 모바일 터치로 유닛을 골라 체력·보호막·상태와 소속을 본다. 액티브 보유 유닛의 상세에는 스킬 이름과 준비·시전·재사용 상태를 표시한다. 전투 기록에는 퇴장 시점, 시전 완료·중단, 적용 대상, 피해·회복·보호막 수치를 남긴다. |
| 교전 가독성 | 아군 바닥 표식은 청록 원, 적은 보라 각형을 쓴다. 피해를 받거나 선택된 유닛과 보스는 체력을 표시한다. 도발·부활 등 지속 상태는 체력바 옆, 심해 파동은 해당 열 바닥에 윤곽과 사선으로 표시한다. 분열 전후에는 두 생성점을 표시하고 보스 이름 아래에 남은 분열체 수를 표시한다. |
| 결과 | 승패, 침식도 변화, 다음 라운드 최대 골드 및 양쪽 생존 수를 보여 준다. 아래에 첫 퇴장, 권능이 준 피해, 대장 패시브의 대상과 유효 피해·경감·회복을 제공한다. 다음 선술집·예언·런 결과로 이어간다. |

## 첫 플레이테스트

1. **카메라.** 같은 장면을 45°·55°·65°로 비교한다. 480×270 전장 렌더를 PC의 16:9와 가로 모바일의 20:9 화면에 배치해 아군 최대 24명과 적 기본 슬롯 6칸, 최종 보스 분열 직후를 캡처한다. 전후열과 좌·중·우, 도발과 부활 표식, 파동의 위험 열, 분열체 두 기의 위치를 확대 없이 확인한다.
2. **배치 차이.** 같은 기물과 성장 상태로 탱커를 오른쪽에서 왼쪽으로 옮겨 R08E를 재생한다. 오른쪽 적 도발, 왼쪽 파동 예고, 첫 피해 대상과 후열의 첫 공격 시간을 비교한다. R07→R08, R11→R12는 각각 같은 성장 상태를 고정한 비교와 라운드별 성장을 허용한 비교를 실행한다. [적 편성 75개](enemy-waves.md)
3. **사건과 재현성.** 3초 예고 후 열 이동, 사거리 안에 들어온 도발, 에다의 보호막 완전 흡수, 나린의 다중 피해, 오르 발동 직전 종료, R15A 분열 및 동시 전멸을 확인한다. 같은 시드에 대해 1×와 2×에서 승패·침식도·사건 순서가 같아야 한다. 발동하지 않은 전투를 포함해 대장별 발동률을 기록한다.
