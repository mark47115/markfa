# Tavern Heros · 기획서 효과 요약

## 핵심 능력

| 대장 | 효과 |
| --- | --- |
| 용병대장 로언 | 후보 2장 중 1장 3골드 고용. 1라운드부터, 사용 후 3라운드 뒤 재사용(최대 5회). 고용 확정 시 비용·횟수 차감 |
| 균열 학자 미레 | 이번과 다음 2라운드의 고정 적 편성·권능·발동 시점 공개 |
| 정비공 토린 | 방문당 1회·1골드 → 지정 기물 최종 주력 공격력 +1·최대 체력 +2(이번 전투). 판매 시 취소·환불 없음 |
| 길잡이 세라 | 방문당 1회·무료 → 미구매 탁자 1칸의 후보 교체. 잠금·봉인 제외, 다른 후보가 있어야 사용 |
| 개척대장 브린 | 레벨업 비용 −1골드(최저 0, 원정당 최대 4골드 절약) |
| 성문수호자 에다 | 최전방 원본 주력의 첫 기본 공격 체력 피해 절반(올림, 최대 3) 경감. 보호막이 모두 막으면 기회 유지 |
| 척후대장 라크 | 아군 원본 첫 기본 공격 적중 → 같은 열의 아직 미적중 원본 중 공격력 최고 대상의 다음 기본 공격 피해 +2. 전투당 1회 |
| 야전의사 나린 | 체력 피해를 받고 40% 이하로 생존한 첫 원본 아군 회복 3. 동시에는 최저 체력 비율 우선, 전투당 1회 |
| 종루지기 오르 | 6초에 서로 다른 기물의 생존 원본 주력 중 공격력 상위 최대 2명 공격속도 +20%(4초) |
| 신호수 루메 | 3초에 미공격·사거리 밖 조준 중 최장 이동 원본 1명이 도달 가능한 최근접 적으로 재조준(도발 우선). 이동속도 +35%(최대 3초, 공격 시작 시 종료) |
