# Tavern Heros 개발 순서

첫 슬라이스는 풀밭에서 외신의 문턱으로 이어지는 1인 15라운드 원정이다. 선술집에서 고용하고 바깥 대기장에서 진형을 정한다. [신규 원정·경제·침식 규칙](run-rules.md)

[현재 아트 방향성](../art-direction.html) · [초기 기획 PDF](../references/rift-tavern-game-summary.pdf)

| 단계 | 산출물 | 완료 확인 |
| --- | --- | --- |
| M0 | Unity 비의존 C# 규칙, 골드 충전과 침식도, 6기물·두 진형, 15라운드의 75개 적 편성, 밸런스 봇 | 시드 재현, 배치·골드·침식 판정 검증, 200개 시드 원정 및 클리어율 20~50% 목표 검토 |
| M1 | Unity 6000.6.9f1 프로젝트, 2D URP 및 Core 참조 | 대상 Unity 버전에서 배치 컴파일과 테스트 통과 |
| M2 | 480×270 기준 전장, 선술집·덱 전환, 적 예고, 전투 재생, 침식 결과 화면 | 화면 왕복 없이 고용 가능, 두 진형의 배치와 최종 보스 판정 확인 |
| M3 | 고정 시드 3라운드 화면 기록, 프로젝트 안내와 Workspace 카드 | 실제 게임 화면과 동작 확인 후 사용자 플레이 검토 |

슬라이스는 골드 한 종류로 운용하는 1인 15라운드 런이다. 화면은 가로 모바일 또는 PC를 기준으로 제작한다. [화면과 입력](../sections/08-ui.md)
