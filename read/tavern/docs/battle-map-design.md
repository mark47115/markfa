# Tavern Heros · 1–15라운드 전투 맵

변경 초소 앞에서 출발해 시드는 숲, 무너진 관문, 심층 동굴을 지나 삼키는 자의 균열에 닿는다. 초반엔 길과 전열을 읽고, 중반엔 낮은 장애물의 안팎으로 접근한다. 최종전은 넓은 광장에서 보스와 호위의 위치를 읽는 데 집중한다. 4·8·12라운드 뒤의 예언은 기존 원정 흐름을 따른다. [전장 도면](../battle-maps.html) · [원정 규칙](run-rules.md)

## 가로 평면과 전장 연결

왼쪽은 아군 출전 구역, 오른쪽은 적군 출전 구역이고 가운데는 교전면이다. 가로 55° 보기는 가로 평면과 같은 방향에서 지면 기준 55°로 내려다본다. 두 보기에서 같은 지점의 가로 위치가 일치하고, 전술상의 좌·중·우 열은 위·가운데·아래로 보인다.

한 전장의 오른쪽과 다음 전장의 왼쪽은 같은 경계 ID를 참조한다. 경계마다 팔레트, 바닥 무늬, 장식 시드, 길을 잇는 위치를 한 번 정의한다. 예를 들어 1라운드는 왼쪽 초지에서 오른쪽 황토 수레길로 바뀌고, 2라운드는 같은 수레길에서 시작해 오른쪽 솔숲으로 접어든다. 「다음 전장과 이어 보기」에서 두 전장의 교전면을 맞붙여 연결부를 확인할 수 있다.

| 전장 | 왼쪽에서 오른쪽으로 |
| --- | --- |
| 1 | 초소 앞 밝은 풀밭 → 황토 수레길 |
| 2 | 황토 수레길 → 솔숲 가장자리 |
| 3 | 솔숲 가장자리 → 시드는 솔숲 |
| 4 | 시드는 솔숲 → 엉킨 고목 뿌리 |
| 5 | 엉킨 고목 뿌리 → 마른 물길 둔덕 |
| 6 | 마른 물길 둔덕 → 관문 앞 낡은 돌길 |
| 7 | 관문 앞 낡은 돌길 → 무너진 성벽 자락 |
| 8 | 무너진 성벽 자락 → 청회색 맥의 운반로 |
| 9 | 청회색 맥의 운반로 → 심층 동굴 입구 |
| 10 | 심층 동굴 입구 → 종유석의 낮은 분지 |
| 11 | 종유석의 낮은 분지 → 먹보라 수정맥 |
| 12 | 먹보라 수정맥 → 갈라진 보랏빛 지층 |

| 14 | 석교로 이어지는 떠 있는 바위 → 균열 앞 퇴색한 석판 |
| 15 | 균열 앞 퇴색한 석판 → 외신의 균열 |

## v11 해상도 조정

v10은 240×135 격자(도트 한 칸 7px)에 공통 팔레트 27~40색을 썼다. 원본과 키 아트는 한 칸을 약 5px로 그렸다. 7px 칸으로 옮기는 과정에서 창틀, 외곽선, 꽃술 같은 한 칸 크기의 형태가 주변 색에 섞였다. 목표 명도에 맞춘 색 변환도 화면을 탁하게 만들었다.

v11은 같은 원본을 336×189 격자(한 칸 5px)로 옮긴다. 맵마다 원본에 실제로 있는 색 가운데 최대 64색을 Lab 거리로 고르고, 디더 없이 칸마다 가장 많은 색을 쓴다. 목표 명도에 맞춘 색 변환은 하지 않는다. 그래서 아래 v10 단계별 실측값은 v11에서 다시 재지 않았다. 오염 진행은 v10 원본의 색과 형태를 따른다.

- 15장 모두 1680×945이고, 5×5 블록이 한 색이며, 맵마다 64색 이하다. 인접한 14곳은 경계 열이 일치한다.
- `.venv-video/Scripts/python qa/build-battle-map-v11.py --check`로 검사한다. 인수 없이 실행하면 원본에서 다시 만든다.

## 좌표와 층

- **교전면**은 20×16 월드 단위다. 원점은 바닥 중앙, 전술상 오른쪽이 +x, 아군 쪽이 +z다. 검산 격자는 0.25 단위다. 도면의 55° 보기는 가로 평면에 수평축 기준 기울기를 적용한 직교 투영이다.
- **출전**은 기존 2열 종대·횡대의 기물 6칸과 적 전후열 6칸 좌표를 사용한다. 기물 내부 배치는 기준점에서 x ±1.35, z ±0.45 범위를 검산했다. 열 경계는 x = −3.75, +3.75다. 한 라운드의 A–E 편성은 같은 맵을 공유한다. [전투 좌표](combat-design.md) · [편성 75개](enemy-waves.md)
- **바닥**의 풀, 얕은 물 자국, 타일, 수정맥은 이동 가능한 시각 요소다. 큰 나무·기둥·균열은 경계 밖에 둔다. 교전면은 평탄하다.
- **장애물**은 −2 ≤ z ≤ 2에 놓인 사각 이동 차단안이다. 범위 형식은 `[minX, minZ, maxX, maxZ]`다. 실제 충돌체와 프리팹은 후속 엔진 구현에서 결정한다. 지형의 역할은 이동 경로를 바꾸는 데 한정하고, 피해·보너스·사거리 판정은 기존 규칙을 따른다.
- **이동 경로** 점선은 출발과 합류를 잇는 검토용 중심선이다. 실제 자동 전투에서 만나는 위치는 유닛의 이동과 조준에 따라 달라진다. JSON에는 전장별 경로, 장애물 ID와 범위, 출전 좌표가 들어 있다. [편집용 좌표 JSON](../battle-maps.json)
- **최종전**의 분열 예시는 보스의 시작 슬롯을 기준으로 한다. 실제 전투는 사망 직전 칸을 비우고 같은 줄에서 가까운 빈칸부터 고른 뒤, 가용 자리가 모자라면 다른 줄을 쓴다. 도면에는 호위 시작 슬롯을 함께 표시한다. [분열 규칙](enemy-character-design.md)

인접 전장 14쌍이 같은 경계를 공유하는지 검사했다. 15개 전장의 경로 45개에서 **폭 2.4 단위**를 확보했다. 시험 반경 0.45와 0.75 단위로 아군 두 진형의 출전 범위와 적 6칸을 연결하는 격자 경로가 있는지 검사했다. 가장 긴 예시 우회는 5라운드 중앙의 **2.23 단위**로, 이동 속도 2.8 단위/초 기준 약 **0.80초**의 거리 차이다. 5라운드의 반대편 우회도 같은 폭을 확보했다. 최종전 5후보 전부에서 분열 예시 두 자리가 호위와 겹치지 않았다.
