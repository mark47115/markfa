# Cavern Heros 이미지 폰트

두 서체는 같은 도트 자형을 공유한다. 본문용은 선술집의 양피지색 한 단계로 획의 빈 공간과 자간을 살렸다. 연출용은 호박색 금속면, 밝은 위쪽 날, 짙은 갈색 테두리와 오른쪽 아래 그림자로 전투 화면에서 강조한다.

| 서체 | 쓰는 곳 | 기본 크기와 줄 높이 | 글자와 파일 |
| --- | --- | --- | --- |
| Cavern Text | 본문, 설명, 기물명, 골드와 침식도 | 12px · 줄 높이 16px | 한글 완성형 11,172자 포함 총 11,941자. `text/text.fnt`와 1024×1024 PNG 3장 |
| Cavern Impact | 전투 피해, 치명타, 회복, 상태 표시 | 24px · 줄 높이 34px | 숫자, 영문, 부호, 지정 전투 문구에 쓰는 한글 포함 166자. `impact/impact.fnt`와 512×512 PNG 1장 |

## 게임에서 사용할 때

- 폰트별 `.fnt`와 해당 폴더의 PNG를 함께 넣는다. AngelCode BMFont 텍스트 형식의 `page`와 `char` 필드에서 텍스처, 표시 크기, 베이스라인과 자간을 읽는다. [BMFont 파일 형식](https://angelcode.com/products/bmfont/doc/file_format.html)
- 텍스처는 최근접 필터를 쓰고 압축·밉맵을 끈다. 기본 크기 또는 정수배로 그리면 도트 모서리가 고르게 보인다. 본문은 어두운 목재색 패널에서, 연출용은 전장 위에 얹어 쓴다.
- 입력은 NFC로 정규화한다. 등록되지 않은 연출용 한글은 본문용으로 대체할 수 있다. 두 서체 모두 숫자의 이동 폭을 고정했다. 지원하는 연출 문구와 기호는 [매니페스트](manifest.json)에 있다.
